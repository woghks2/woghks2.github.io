# 1. 혼동 행렬 (Confusion Matrix)



분류 모델의 예측 결과를 평가할 때 단순히 "전체 중 몇 개를 맞혔는가(정확도)"만 보면 모델의 진짜 성능을 놓치기 쉽습니다. 예를 들어 정상 데이터가 99개이고 이상 데이터가 1개인 경우, 모델이 무조건 '정상'이라고만 답해도 정확도는 99%가 나오기 때문입니다.

혼동 행렬은 모델의 예측값과 실제 정답의 일치 여부를 교차표 형태로 나누어, 모델이 어떤 종류의 정답을 잘 맞히고 어떤 오답을 내고 있는지 한눈에 파악할 수 있도록 돕는 도구입니다.

## 2. 기본 구성과 4가지 요소

이진 분류를 기준으로 실제 클래스와 모델이 예측한 클래스를 비교하면 다음과 같이 4가지 경우로 나뉩니다.

| 모델 예측 | 실제 Positive (1) | 실제 Negative (0) |
|---|---:|---:|
| 예측 Positive (1) | TP | FP |
| 예측 Negative (0) | FN | TN |

- TP: 실제 양성인 데이터를 모델이 양성으로 올바르게 맞힌 경우 (예: 실제 암 환자를 암이라고 진단)

- TN: 실제 음성인 데이터를 모델이 음성으로 올바르게 맞힌 경우 (예: 실제 정상인을 정상이라고 진단)

- FP: 실제는 음성인데 모델이 양성이라고 잘못 예측한 경우 (예: 정상인을 암 환자로 오진)

- FN: 실제는 양성인데 모델이 음성이라고 잘못 예측한 경우 (예: 암 환자를 정상인으로 오진하여 방치)

여기서 앞 글자(T/F)는 "예측이 맞았는가 틀렸는가"를 뜻하고, 뒷 글자(P/N)는 "모델이 무엇으로 예측했는가"를 뜻합니다.

## 3. 주요 평가 지표

혼동 행렬의 4가지 값을 조합하여 문제의 특성에 맞는 다양한 평가 지표를 유도할 수 있습니다.

### 1. 정밀도 (Precision)

모델이 양성(Positive)이라고 예측한 것 중, 실제로 맞힌 양성의 비율입니다.

$$\text{Precision} = \frac{\text{TP}}{\text{TP} + \text{FP}}$$

- 핵심: 모델이 헛발질(FP, 1종 오류)을 얼마나 적게 했는가를 봅니다.

- 중요한 상황: 아무 일도 없는데 불필요한 조치를 취했을 때 큰 손해를 보는 경우에 중요합니다. 예를 들어 정상 업무 메일을 스팸으로 오분류하여 삭제해 버리면 비즈니스에 치명적이므로, 정밀도를 높여 확실한 스팸만 잡아내야 합니다.

### 2. 재현율 (Recall / Sensitivity)

실제 양성(Positive)인 데이터 중, 모델이 놓치지 않고 찾아낸 비율입니다.

$$\text{Recall} = \frac{\text{TP}}{\text{TP} + \text{FN}}$$

- 핵심: 실제 사건을 놓치고 방치(FN, 2종 오류)하는 것을 얼마나 잘 막았는가를 봅니다.

- 중요한 상황: 조치를 취하지 않고 방치했을 때 수습 불가능한 피해가 발생하는 경우에 중요합니다. 예를 들어 암 진단이나 금융 사기 탐지에서는 환자나 사기범을 놓치면 치명적이므로, 다소 과민하게 반응(FP 증가)하더라도 재현율을 우선적으로 끌어올려야 합니다.

### 3. F1-Score

정밀도와 재현율의 조화평균(Harmonic Mean)입니다.

$$\text{F1-Score} = 2 \times \frac{\text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}}$$

정밀도와 재현율은 한쪽을 극단적으로 높이면 다른 한쪽이 떨어지는 트레이드오프(Trade-off) 관계를 가집니다. 단순 산술평균을 쓰면 한 지표가 극단적으로 낮아도 평균값이 그럴듯하게 왜곡될 수 있기 때문에, 둘 중 하나라도 낮으면 큰 페널티를 주는 조화평균을 사용하여 두 지표의 균형을 종합적으로 평가합니다.

## 4. 정리

혼동 행렬은 모델의 예측을 TP, TN, FP, FN 네 가지로 세분화하여 모델의 실제 성능을 들여다보는 기초 도구입니다.

단순 정확도만으로는 파악하기 힘든 클래스 불균형 문제를 드러내 주며, 풀고자 하는 문제에서 "불필요하게 행동해서 보는 손해(1종 오류/FP)"가 더 큰지, 아니면 "가만히 냅뒀다가 보는 손해(2종 오류/FN)"가 더 큰지에 따라 정밀도와 재현율 중 어떤 지표를 중점적으로 최적화해야 할지 결정하는 기준이 됩니다.

## 5. Q&A

> [!question] 산술평균 대신 굳이 조화평균(F1-Score)을 쓰는 이유는 무엇인가요?
> 
> 어느 한 지표가 극단적으로 낮을 때 평균값이 왜곡되는 것을 막기 위해서입니다.
>
> 예를 들어 Precision이 1.0이고 Recall이 0.04인 모델은 산술평균이 0.52지만, 조화평균인 F1-score는 약 0.077입니다. 한쪽 지표만 높은 모델에 F1-score가 더 큰 불이익을 줍니다.

> [!question] 정확도(Accuracy)는 언제 신뢰할 수 있나요?
> 
> 클래스 비율이 크게 치우치지 않고, FP와 FN의 비용도 비슷할 때 전체적인 정답 비율을 요약하는 지표로 참고할 수 있습니다.
>
> 데이터가 불균형하거나 특정 오류가 더 치명적이면 정확도만으로 모델을 판단하지 않는 편이 좋습니다.

> [!question] 정밀도와 재현율을 둘 다 동시에 100%로 만들 수는 없나요?
> 
> 항상 불가능한 것은 아니지만, 임계값을 조정할 때 두 지표가 서로 반대 방향으로 움직이는 경우가 많습니다.
>
> 임계값을 낮추면 더 많은 Positive를 찾아 Recall이 오르는 대신 FP가 늘어 Precision이 낮아질 수 있습니다. 임계값을 높이면 보통 그 반대 변화가 나타납니다.
