# 03. 이상치 처리

## 개요

이상치(outlier)는 다른 관측값의 분포에서 크게 벗어난 값입니다. 값이 크거나 작다는 이유만으로 오류라고 단정할 수는 없습니다. 센서 고장이나 입력 실수처럼 수정해야 할 값도 있고, 실제로 드물지만 중요한 사건일 수도 있습니다. 먼저 원천 데이터와 측정 단위를 확인하고, 그다음 분석 목적에 맞춰 처리합니다.

## 룰 기반 탐지

룰 기반 탐지는 도메인에서 정한 유효 범위나 논리 조건으로 이상치를 찾습니다. 나이가 음수일 수 없다거나, 센서 값이 장비의 물리적 측정 범위를 넘을 수 없다는 규칙이 예입니다. 데이터 분포를 가정하지 않고 결과를 설명하기 쉬워 원천 오류를 걸러낼 때 유용합니다. 반면 기준을 사람이 정해야 하므로 새로운 상황이나 집단별 차이에 취약하고, 규칙을 너무 좁게 잡으면 실제로 가능한 극단값까지 제외할 수 있습니다.

```python
# 업무 정의상 허용된 범위를 벗어난 측정값 확인
invalid_mask = (
    df["temperature"].lt(-40)
    | df["temperature"].gt(85)
)
invalid_rows = df.loc[invalid_mask]
```

룰 기반 기준은 통계적 이상치와 구분해야 합니다. 값이 업무상 허용 범위 안에 있어도 다른 데이터와 비교하면 드물 수 있고, 반대로 분포에서 멀어 보여도 실제 가능한 값일 수 있습니다.

## IQR 기준

사분위 범위(IQR, Interquartile Range)는 데이터의 가운데 절반이 퍼져 있는 범위입니다. 제1사분위수 Q1과 제3사분위수 Q3의 차이를 계산하고, 보통 Q1보다 1.5×IQR 아래거나 Q3보다 1.5×IQR 위에 있는 관측값을 이상치 후보로 표시합니다.

```python
q1 = df["value"].quantile(0.25)
q3 = df["value"].quantile(0.75)
iqr = q3 - q1

lower = q1 - 1.5 * iqr
upper = q3 + 1.5 * iqr
candidate_mask = df["value"].lt(lower) | df["value"].gt(upper)

candidates = df.loc[candidate_mask]
```

IQR 기준의 장점은 평균과 표준편차보다 극단값 자체에 덜 끌려간다는 점입니다. 그래서 치우친 분포나 일부 큰 값이 섞인 데이터에서 탐색 기준으로 쓰기 좋습니다. 다만 분포의 형태나 업무상 허용 범위는 고려하지 않으므로, 긴 꼬리가 자연스러운 가격·소득 데이터에서는 정상적인 고액 값도 후보가 될 수 있습니다. 보통 1.5×IQR은 후보를 넓게 찾는 기준이고, 더 극단적인 값에 집중할 때는 3×IQR을 참고하기도 합니다. 어느 경계든 자동 삭제 규칙으로 간주하지 않습니다.

## 표준편차 기준

평균과 표준편차를 이용하면 평균에서 몇 표준편차 이상 떨어진 값을 찾을 수 있습니다. 이 방식은 분포가 대칭적이고 정규분포에 가까울 때 해석하기 쉽습니다. 분포가 심하게 치우치거나 이미 극단값이 포함되어 있으면 평균과 표준편차 자체가 영향을 받으므로 IQR 같은 견고한 기준을 먼저 살펴봅니다.

```python
mean = df["value"].mean()
std = df["value"].std()

z_score = (df["value"] - mean) / std
candidate_mask = z_score.abs() > 3
```

Z-score는 계산과 해석이 간단합니다. 평균에서 몇 표준편차 떨어졌는지 하나의 수치로 표현하므로 대칭적이고 정규분포에 가까운 데이터에서 유용합니다. 하지만 평균과 표준편차가 이상치의 영향을 크게 받기 때문에, 치우친 분포에서는 경계가 왜곡될 수 있습니다. 표본이 작거나 데이터에 극단값이 이미 많은 경우에도 안정적이지 않습니다. 임계값 3은 자주 쓰이는 출발점이지 보편적인 정답은 아닙니다.

## 모델 기반 탐지

모델 기반 방법은 여러 피처를 함께 고려해 평소와 다른 조합이나 밀도를 가진 관측값을 찾습니다. Isolation Forest(고립 숲)는 무작위 분할을 반복했을 때 다른 점보다 짧은 경로로 고립되는 샘플을 이상치 후보로 판단합니다. 피처 간 관계가 복잡할 때 단변량 경계보다 유용할 수 있지만, 왜 그 행이 이상치로 잡혔는지 설명하기 어렵고 파라미터와 데이터 구성에 따라 결과가 달라질 수 있습니다.

```python
from sklearn.ensemble import IsolationForest

features = ["temperature", "pressure", "vibration"]
detector = IsolationForest(
    n_estimators=200,
    contamination="auto",
    random_state=42,
)
detector.fit(train_df[features])

# 1은 정상, -1은 이상치 후보
train_df["outlier_flag"] = detector.predict(train_df[features])
valid_df["outlier_flag"] = detector.predict(valid_df[features])
```

`contamination`은 데이터에서 이상치가 실제로 몇 퍼센트인지를 알려주는 정답값이 아닙니다. 탐지 임계값을 정하는 설정이므로, 알려진 사례나 업무 검토 결과를 통해 적절성을 확인해야 합니다. 모델 기반 점수도 이상 여부를 확정하기보다 조사 우선순위를 정하는 신호로 보는 것이 안전합니다.

## 탐지 방법 비교

룰 기반은 기준이 명확하고 설명하기 쉽지만 도메인 규칙을 직접 관리해야 합니다. IQR은 분포가 비대칭이어도 비교적 견고한 단변량 기준이지만 피처 간 조합은 보지 못합니다. Z-score는 대칭 분포에서 간단하고 해석하기 쉽지만 평균과 표준편차에 민감합니다. Isolation Forest 같은 모델 기반 방법은 여러 피처의 조합을 볼 수 있는 대신 설명과 설정 검증이 더 어렵습니다. 먼저 룰 기반으로 명백한 오류를 확인하고, 통계 기준으로 단일 변수의 후보를 살핀 뒤, 필요할 때 다변량 모델을 검토하는 흐름이 실용적입니다.

## 처리 방법

원천 오류라면 가능한 경우 값을 바로잡습니다. 정상적인 극단값이라면 그대로 유지하거나 로그 변환으로 긴 꼬리를 압축할 수 있습니다. 모델 학습의 안정성을 위해 경계값으로 치환하는 방법도 있지만, 치환은 여러 관측값을 같은 값으로 묶어 분포와 변수 관계를 바꿉니다. 각 방법을 적용한 뒤 성능뿐 아니라 중요한 희귀 사례가 사라지지 않았는지 확인합니다.

```python
import numpy as np

# 음수가 없는 긴 꼬리 변수에 로그 변환 적용
df["value_log"] = np.log1p(df["value"])

# 1·99 백분위 경계 바깥을 경계값으로 제한
low, high = df["value"].quantile([0.01, 0.99])
df["value_clipped"] = df["value"].clip(lower=low, upper=high)
```

행 단위 제거는 해당 행의 다른 유효한 정보까지 함께 버린다는 점을 고려해야 합니다. 사기 탐지나 장애 감지처럼 극단 사례 자체가 찾아야 할 대상인 문제라면 제거가 오히려 목적을 훼손합니다.

## 모델과 스케일링

선형 회귀나 평균·분산에 의존하는 전처리는 극단값의 영향을 크게 받을 수 있습니다. KNN(K-Nearest Neighbors, K-최근접 이웃)이나 SVM(Support Vector Machine, 서포트 벡터 머신)처럼 거리 또는 경계에 민감한 모델도 영향을 받을 수 있습니다. 결정 트리 계열은 스케일에 상대적으로 덜 민감하지만, 오류값이나 비현실적인 관측값을 자동으로 해결하지는 않습니다.

## 정리

이상치 탐지는 룰 기반, 통계 기반, 모델 기반으로 나눠 생각할 수 있습니다. 룰 기반은 명백한 업무 범위 위반을 잡고, IQR과 Z-score는 한 변수의 분포에서 벗어난 값을 찾으며, Isolation Forest는 여러 피처의 조합을 살핍니다. 각 방법이 표시한 값은 우선 검토할 후보입니다. 원천 오류인지 유효한 희귀 사례인지 확인한 뒤 제거·수정·치환·변환·유지 중 목적에 맞는 처리를 선택합니다.

### Q&A

> [!question] IQR은 무엇의 약자인가요?
>
> IQR은 Interquartile Range의 약자로, 한국어로 사분위 범위라고 합니다. 제3사분위수(Q3)에서 제1사분위수(Q1)를 뺀 값이며, 가운데 50% 데이터가 퍼진 범위를 나타냅니다.

> [!question] IQR 경계 밖의 값을 전부 제거하면 되나요?
>
> 아닙니다. IQR은 이상치 후보를 표시하는 규칙입니다. 측정 오류인지 의미 있는 희귀 사례인지 확인한 뒤 처리해야 합니다.

> [!question] 이상치를 평균으로 바꿔도 되나요?
>
> 가능하지만 평균 자체가 극단값에 영향을 받을 수 있고, 여러 관측값이 같은 값으로 몰리면서 변수 관계가 달라질 수 있습니다. 중앙값이나 경계값 치환, 변환, 유지와 비교해 선택합니다.
