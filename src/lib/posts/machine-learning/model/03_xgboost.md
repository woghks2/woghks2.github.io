# 03. XGBoost

랜덤 포레스트가 여러 개의 깊은 트리를 **독립적으로** 만들어 투표나 평균으로 결과를 합치는 배깅(Bagging) 모델이라면, XGBoost는 앞선 트리들이 남긴 오차(잔차)를 다음 트리가 이어받아 하나씩 보완해 나가는 부스팅(Boosting) 모델입니다.

일반적인 결정 트리는 지니 불순도처럼 "데이터를 얼마나 순수하게 나누는가"를 봅니다. 반면 XGBoost는 손실 함수(Loss)를 직접 정의하고, "어떻게 트리를 나눠야 전체 오차가 가장 많이 줄어드는가?"를 핵심 기준으로 삼습니다.

---

## 1. 트리 모델은 비선형을 어떻게 학습하는가? (과적합과의 차이)

흔히 "트리 모델은 비선형 관계를 알아서 잘 잡는다"고 말합니다. 그렇다면 이것은 과적합의 다른 이름일까요? 결론부터 말하면 **전혀 아닙니다.**

* **선형 모델의 한계**: $y = ax + b$ 같은 직선/평면만 그을 수 있어, 나이에 따른 소득(U자형 곡선)이나 XOR 같은 상호작용 패턴을 풀려면 피처 엔지니어링($x^2, x_1 \times x_2$)을 수동으로 넣어줘야 합니다.
* **트리의 비선형 근사**: 트리는 축에 수직인 조건 분기(`If-Else`)를 통해 공간을 직사각형 격자로 쪼개며, **계단 함수(Step Function)** 형태로 복잡한 곡선을 근사해 냅니다.
* **과적합과의 경계**: 데이터 100개에 질문 100개를 던져 노이즈까지 외우면 과적합이지만, XGBoost는 **얕은 깊이 제약 + 사후 가지치기 + 학습률 축소**라는 강력한 규제를 걸어 '의미 있는 거시적 비선형 패턴'만 남깁니다.

---

## 2. 목적 함수 (Objective Function)

XGBoost는 $t$번째 새로운 트리를 만들 때 아래의 목적 함수 $\mathcal{L}^{(t)}$을 가장 작게 만드는 것을 목표로 합니다.

$$\mathcal{L}^{(t)} = \sum_{i=1}^n \text{Loss}(y_i, \, \hat{y}_i^{(t-1)} + f_t(x_i)) + \Omega(f_t)$$

앞부분은 실제 정답과 현재 트리까지 합산된 예측값 사이의 오차(Loss)이고, 뒷부분 $\Omega(f_t)$는 이번에 추가될 트리 $f_t$가 너무 복잡해지지 않도록 막는 규제(Penalty)입니다.

$$\Omega(f_t) = \gamma T + \frac{1}{2} \lambda \sum_{j=1}^T w_j^2$$

* **리프 노드 개수 제약 ($\gamma T$)**: 트리에 리프 노드($T$)가 하나 늘어날 때마다 손실 점수에 $\gamma$만큼의 패널티를 줍니다.
* **출력 가중치 억제 ($\lambda w_j^2$)**: 각 리프 노드가 내놓는 예측값($w_j$)의 크기가 너무 극단적으로 커지지 않도록 눌러줍니다 (L2 규제).

---

### 2차 테일러 전개를 사용하는 이유

임의의 복잡한 손실 함수에서 최적의 분기를 매번 해석적으로 구하는 것은 불가능합니다. 따라서 XGBoost는 이전 스텝의 예측값 $\hat{y}^{(t-1)}$ 주변을 2차 테일러 전개(Taylor Expansion)로 근사합니다.

$$\text{Loss} \approx \text{상수항} + g_i f_t(x_i) + \frac{1}{2} h_i f_t^2(x_i)$$

* **1차 미분 $g_i$ (Gradient)**: 오차의 방향과 크기 ($\frac{\partial \text{Loss}}{\partial \hat{y}}$)
* **2차 미분 $h_i$ (Hessian)**: 오차 곡선의 곡률 ($\frac{\partial^2 \text{Loss}}{\partial \hat{y}^2}$, 2차 미분 기반 신뢰도 가중치)

일반 GBM은 1차 미분(방향)만 보고 학습률이나 step size를 별도 선 탐색(Line search)으로 찾아야 했습니다. 반면 XGBoost는 곡률($h_i$) 정보까지 함께 고려하여 최적의 수정 폭을 수학적으로 단번에 계산해 냅니다.

---

## 3. 리프의 최적 예측값과 품질 점수

어떤 리프 노드 $j$에 모인 데이터들의 기울기 합을 $G_j = \sum_{i \in I_j} g_i$, 곡률 합을 $H_j = \sum_{i \in I_j} h_i$라고 두면, 이 노드가 내놓아야 할 최적의 출력값 $w_j^*$는 2차 함수 꼭짓점 공식을 통해 유도됩니다.

$$w_j^* = -\frac{G_j}{H_j + \lambda}$$

* **분자 ($G_j$)**: 노드에 모인 잔차(오차)의 총합입니다. 오차가 클수록 이를 메우기 위해 내놓는 보정값도 커집니다.
* **분모 ($H_j + \lambda$)**: 데이터 확신도($H_j$)에 L2 규제 파라미터($\lambda$)가 더해집니다. 데이터 수가 적거나 곡률이 애매하면 분모가 커져 예측값이 0 쪽으로 강하게 수축(Shrinkage)됩니다.

이 최적값을 대입하여 식을 정리하면, 해당 노드가 오차 감소에 얼마나 기여하는지 나타내는 품질 점수(Quality Score)가 나옵니다.

$$\text{Score} = -\frac{1}{2} \frac{G_j^2}{H_j + \lambda}$$

---

## 4. 노드 분할(Gain)과 사후 가지치기 (Post-Pruning)

XGBoost는 트리를 나눌 때 불순도가 아니라, "분할 전후로 오차 품질 점수가 얼마나 개선되었는가(Gain)"를 봅니다.

$$\text{Gain} = \frac{1}{2} \left[ \frac{G_L^2}{H_L + \lambda} + \frac{G_R^2}{H_R + \lambda} - \frac{(G_L + G_R)^2}{H_L + H_R + \lambda} \right] - \gamma$$

* **대괄호 항**: (좌측 자식 점수 + 우측 자식 점수) - (부모 노드 점수). 즉, 분할로 얻은 순수 오차 개선량입니다.
* **$-\gamma$**: 노드가 분할되면서 리프가 1개 순증가함에 따라 지불해야 하는 구조적 비용입니다.

### 사후 가지치기(Post-Pruning)의 작동 원리
LightGBM처럼 분할 시점에 Gain이 작으면 아예 분할을 멈추는 방식(Pre-Pruning)과 달리, XGBoost는 독특한 방식을 취합니다.

1. 우선 설정된 **`max_depth`까지 탐욕적으로 층별 분할(Level-wise)을 끝까지 진행**합니다.
2. 트리가 완성되면 최하단 리프 노드부터 루트 노드 방향으로 **거꾸로 거슬러 올라가며 Gain을 검사**합니다.
3. 분할의 $\text{Gain} < 0$ (즉, 개선량이 벌점 $\gamma$보다 작음)인 노드를 잘라냅니다.

> **💡 왜 굳이 끝까지 갔다가 쳐낼까?**  
> 당장 첫 번째 분기에서는 Gain이 미미하거나 마이너스처럼 보여도, 그 바로 다음 깊이에서 극적인 손실 감소가 일어나는 경우가 많습니다. 끝까지 내려갔다가 역방향으로 쳐냄으로써 **미래의 큰 이득을 놓치지 않으면서도 과적합을 깔끔하게 통제**할 수 있습니다.

## 5. 부스팅 루프: 매 라운드마다 무엇이 바뀌는가?

XGBoost가 트리를 100개 만든다는 것은, 깊이 6짜리 동일한 트리를 100번 복사하는 것이 아닙니다.

1. 잔차 계산 → 현재 모델의 오차로부터 각 데이터의 Gradient(g)와 Hessian(h) 산출
2. 트리 생성 → max_depth까지 오차 개선을 목표로 Level-wise 분할
3. 가지치기 → 하단부터 거슬러 올라가며 Gain < gamma인 가지 절단
4. 축소 반영 → 완성된 트리 예측값에 학습률(eta)을 곱해 모델에 누적 덧셈
5. 다음 턴 → 오차가 갱신되므로 타깃값(g, h)이 완전히 바뀌며 1단계로 복귀


### 왜 매번 완전히 다른 질문(분기)이 나오는가?
* **트리 1번**: 실제 정답($y$)의 거대한 줄기를 맞춥니다. 쉬운 데이터와 주력 피처 위주로 큰 분기가 일어납니다.
* **트리 2번 이후**: 이미 맞춘 데이터는 오차가 0에 가까워져 $g_i \approx 0$이 되므로 Gain 계산에 거의 기여하지 않습니다. 반면 **앞선 트리가 크게 틀린 어려운 데이터들만 높은 $g_i$ 값을 가집니다.**
* 결과적으로 매 라운드마다 데이터 포인트들의 중요도(가중치)가 바뀌어 **후보 분기점들의 Gain 순위가 완전히 역전**되며, 놓친 패턴을 정밀 타격하는 완전히 새로운 트리가 만들어집니다.

### 학습률(`learning_rate`, $\eta$)의 본질: 조심스러운 발걸음
만약 새로 만든 트리의 예측값을 100%($\eta = 1.0$) 그대로 더해버리면, 특정 트리가 노이즈나 이상치에 과적합되었을 때 모델 전체가 휘둘리게 됩니다.

$$\hat{y}^{(t)} = \hat{y}^{(t-1)} + \eta f_t(x)$$

XGBoost는 트리가 도출한 최적값에 **$\eta = 0.1$ 같은 작은 가중치만 곱해서 찔끔 반영**합니다. 새 트리의 주장을 10%만 조심스럽게 믿고 넘어가 다음 트리에 보완 기회를 넘김으로써, 수백 개의 다양한 시각을 가진 얕은 트리들이 협력하는 견고한 일반화 경계가 형성됩니다.

## 하이퍼파라미터 매핑

| 파라미터 | 수식 연결점 | 역할 및 직관 |
| :--- | :--- | :--- |
| `learning_rate` ($\eta$) | $\hat{y} \leftarrow \hat{y} + \eta f(x)$ | 새 트리의 오차 보정값 반영 비율. 작을수록 모델이 신중해짐 |
| `gamma` | $\text{Gain} - \gamma$ | 분할을 허용하기 위한 최소 이득 역치. 클수록 사후 가지치기가 공격적으로 일어남 |
| `reg_lambda` ($\lambda$) | 분모의 $+ \lambda$ | 리프 출력값 $w^*$의 크기를 0 쪽으로 억제하는 L2 정규화 |
| `min_child_weight` | 분모의 $H_j$ | 리프 노드가 가져야 할 최소 Hessian 합. 너무 적은 샘플 단위의 쪼개짐 방지 |
| `max_depth` | 트리 탐색 한계선 | 사후 가지치기 전 최대로 파고 내려갈 수 있는 층수 제한 |

## 정리 및 Q&A

1. **비선형 모델링**: 트리는 구간 분할(Step function)을 통해 복잡한 비선형/상호작용 곡선을 자연스럽게 학습합니다.
2. **목적 함수 기반 분할**: 단순 불순도가 아니라, 2차 테일러 전개로 유도된 엄밀한 손실 함수 개선량(Gain)을 기준으로 분기합니다.
3. **규제와 앙상블**: `max_depth`로 파고 `gamma`로 쳐낸 정제된 트리에 `eta`를 곱해 조금씩 누적함으로써, 편향(Bias)을 낮추면서도 분산(Variance, 과적합)을 철저히 억제합니다.

> [!question] 트리 모델이 비선형 패턴을 잘 잡는다는 건 과적합 아닌가요?
>
> 아니다. 선형 모델이 표현하지 못하는 $U$자형 곡선이나 변수 간 상호작용(XOR)을 If-Else 계단식 구간 분할로 유연하게 근사해 내는 능력이다. 잎 노드를 무한정 쪼개지 않도록 깊이와 규제를 걸어주면, 노이즈 암기가 아닌 실제 데이터의 비선형 분포를 훌륭하게 일반화한다.

> [!question] XGBoost의 사후 가지치기(Post-Pruning)는 왜 Level-wise와 함께 쓰이나요?
>
> 탐욕적 알고리즘(Greedy)의 한계상, 당장 눈앞의 분기 Gain은 음수여도 바로 다음 단계에서 큰 폭의 오차 감소가 일어날 수 있다. 따라서 우선 `max_depth`까지 균형 있게 내려간 뒤 역방향으로 Gain을 검사하여 잘라냄으로써, 근시안적 분할 중단(Pre-pruning)의 위험을 피하고 전역 최적에 더 가까운 트리를 얻는다.

> [!question] Random Forest와 XGBoost의 과적합 관리 철학 차이는 무엇인가요?
>
> Random Forest는 **과적합되기 쉬운 깊은 트리들을 독립적으로 만들어 평균을 냄으로써 분산(불안정성)을 줄이는 전략**이다. 반면 XGBoost는 **단순하고 얕은 트리들을 만들어 오차를 순차적으로 보정(편향 감소)하되, `learning_rate`, `gamma`, `lambda`의 삼중 규제로 과적합을 틀어막는 전략**이다.

본 포스팅은 개인적인 학습 내용을 바탕으로 작성되었으며, 가독성과 내용 보완을 위해 생성형 AI의 도움을 받아 재작성되었습니다.
