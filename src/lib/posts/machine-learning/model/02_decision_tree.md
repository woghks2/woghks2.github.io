# 02. 결정 트리 (Decision Tree)

결정 트리는 조건에 따라 데이터를 나누고, 각 데이터가 어떤 클래스에 속하는지 예측하는 모델입니다. 연속형 값을 예측하는 회귀 문제에도 사용할 수 있지만, 이번 글에서는 분류를 기준으로 정리하겠습니다.

모델은 루트 노드에서 시작해 조건을 하나씩 확인하면서 아래로 이동합니다. 마지막 리프 노드에 도착하면 그 노드에 모인 데이터의 클래스를 바탕으로 예측합니다. 예측 결과와 실제 클래스를 비교하면 모델이 얼마나 잘 분류했는지 평가할 수 있습니다.

트리의 깊이가 깊어지면 데이터를 더 세밀하게 나눌 수 있습니다. 학습 데이터에서는 성능이 좋아질 수 있지만, 분기를 계속 늘리면 일부 샘플의 우연한 패턴이나 잡음까지 학습하는 과적합이 발생할 수 있기에 최대 깊이나 리프 노드의 최소 샘플 수를 함께 살펴봐야 합니다.

## 지니 불순도

트리를 만들 때는 현재 노드를 어떤 기준으로 나눌지 결정해야 합니다. 분류에서 자주 사용하는 기준 중 하나가 지니 불순도입니다. 한 노드에 있는 클래스 비율을 $p_1, p_2, \dots, p_k$라고 하면 지니 불순도는 다음과 같이 계산합니다.

$$Gini = 1 - \sum_{i=1}^{k} p_i^2$$

노드에 한 클래스만 있다면 해당 클래스의 비율은 1이고 나머지는 0입니다. 따라서 지니 불순도는 $1 - 1^2 = 0$이 됩니다. 반대로 여러 클래스가 비슷한 비율로 섞여 있을수록 지니 불순도는 커집니다. 즉, 값이 작을수록 한 노드 안의 클래스가 더 잘 모여 있다고 볼 수 있습니다.

그렇다면 트리는 이 값을 어떻게 사용할까요? 분할 전 노드의 불순도만 보는 것이 아니라, 데이터를 나눈 뒤 만들어지는 자식 노드들의 불순도를 비교합니다. 자식 노드의 데이터 수를 반영해 가중평균을 구하고, 분할 전보다 불순도가 얼마나 줄었는지 계산합니다.

$$\text{Weighted Gini} = \sum_{j=1}^{m} \frac{N_j}{N} Gini_j$$

여기서 $N$은 분할 전 노드의 데이터 수이고, $N_j$는 분할 후 $j$번째 자식 노드의 데이터 수입니다. 트리는 이 분할 후 불순도가 낮아지도록, 다시 말해 불순도 감소량이 커지는 분할을 선택합니다. 데이터가 적은 노드와 많은 노드가 같은 비중으로 반영되지 않도록 자식 노드의 데이터 수를 가중치로 사용합니다.

## CART

CART는 현재 노드에서 가능한 분할 후보를 살펴보고, 각 후보의 불순도 감소량을 계산해 가장 좋은 분할을 선택하는 대표적인 트리 알고리즘입니다. 이 과정을 각 자식 노드에서 반복해 트리를 키워 나갑니다. 매 단계에서는 현재 가장 좋아 보이는 분할을 선택하므로 탐욕적 방식이라고 부릅니다.

연속형 특성은 가능한 모든 값을 그대로 조건으로 쓰는 대신, 특성값을 정렬하고 서로 다른 인접 값 사이를 분할 후보로 둘 수 있습니다. 예를 들어 값이 22, 25, 30, 35라면 23.5, 27.5, 32.5를 기준 후보로 삼아 각각 나눠 봅니다. 각 후보에서 분할 후 불순도를 계산한 다음, 불순도를 가장 많이 줄이는 기준을 고릅니다.

CART의 분류 트리는 보통 한 번에 두 개의 자식 노드를 만드는 이진 분할(한 번에 두 개의 자식 노드를 생성하는 방법)을 사용합니다. 분류에서는 지니 불순도나 엔트로피 같은 기준을 사용할 수 있고, 회귀에서는 분할 후 각 노드의 예측 오차가 얼마나 줄어드는지 비교합니다.

## 정리

결정 트리는 조건을 반복해서 적용해 데이터를 나누고, 리프 노드에서 예측을 만드는 모델입니다. 지니 불순도는 한 노드에 여러 클래스가 얼마나 섞여 있는지 나타내며, 트리는 분할 후 자식 노드의 가중 불순도가 낮아지는 기준을 찾아갑니다.

분할을 계속하면 학습 데이터에 더 잘 맞출 수 있지만, 깊이가 지나치게 커지면 과적합이 발생할 수 있습니다. 따라서 트리의 깊이와 리프 노드 크기를 조절해 검증 데이터에서도 성능이 유지되는지 확인해야 합니다. 이 단일 트리의 불안정성과 과적합을 여러 트리의 결합으로 보완하는 방법이 랜덤 포레스트와 같은 앙상블 모델입니다.

### Q&A

> [!question] Decision Tree는 왜 과적합되기 쉬운가요?
>
> 데이터를 끝까지 잘게 나누면 학습 데이터의 잡음까지 규칙으로 외워버릴 수 있기 때문이다.
> -> 따라서 적합한 파라미터를 설정하여 트리의 분할을 제한해야 한다.

> [!question] Decision Tree는 스케일링이 꼭 필요한가요?
>
> 보통 필요하지 않다. 수치의 절대 크기보다 분할 기준으로만 비교하기 때문이다.
> -> 트리 모델의 장점. 데이터의 크기나 분포에 영향을 덜 받는다.

> [!question] Decision Tree에서 얻은 결과가 최적의 결과인가요?
>
> 지역적으로는 최적인 선택을 반복해서 만든 결과. 즉, 그리디(Greedy) 알고리즘으로 얻은 해이기 때문에 최적해는 아닙니다.
> -> 매 노드에서 “지금 당장 불순도를 가장 많이 줄여주는 분할”을 고르기 때문에 그 순간의 선택은 최적이지만 결과적으로는 근사해에 가깝다.
