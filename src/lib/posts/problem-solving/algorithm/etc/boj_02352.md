# [백준 : 2352. 반도체 설계](https://www.acmicpc.net/problem/2352)

## **목표**

> 반도체 포트에 연결선을 꽂을 때, 교차하지 않고 최대한 많이 연결할 수 있는 개수를 구하는 문제.
> `LIS`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
N = int(input())
arr = list(map(int,input().split()))

LIS = []
for val in arr:
    
    if not LIS or val > LIS[-1]:
        LIS.append(val)
        continue
    
    l,r = -1,len(LIS)
    while l+1<r:
        m = (l+r)//2
        if LIS[m] < val:
            l = m
        else:
            r = m
    LIS[r] = val

print(len(LIS))
```
