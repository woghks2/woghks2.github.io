# [백준 : 1365. 꼬인 전깃줄](https://www.acmicpc.net/problem/1365)

## **목표**

> 전깃줄이 꼬이지 않도록 제거해야 하는 전깃줄의 최소 개수를 구하는 문제.
> `LIS`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
N = int(input())
arr = list(map(int,input().split()))

LIS = []
for val in arr:
    
    if not LIS or val > LIS[-1]:
        LIS.append(val)
        continue
    
    l,r = -1,len(LIS)
    while l+1<r:
        m = (l+r)//2
        if LIS[m] < val:
            l = m
        else:
            r = m
    LIS[r] = val

print(N-len(LIS))
```
