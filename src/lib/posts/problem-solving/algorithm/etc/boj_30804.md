# [백준 : 30804. 과일탕후루](https://www.acmicpc.net/problem/30804)

## **목표**

> 과일탕후루에서 과일 종류가 2가지 이하인 가장 긴 연속 구간의 길이를 구하는 문제.
> `각 시작지점마다 가능한 길이를 찾음. $NlogN$이하로 해야하므로, 투포인터로 찾음`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
from collections import defaultdict as dd

N = int(input())
arr = list(map(int,input().split()))

l,r,count = 0,0,0
infos = dd(int)
answer = 0
while r<N:
    if infos[arr[r]] == 0:
        count += 1
    infos[arr[r]] += 1
    
    while count > 2:
        infos[arr[l]] -= 1
        if infos[arr[l]] == 0:
            count -= 1
        l += 1
    
    answer = max(answer,r-l+1)
    r += 1

print(answer)
```

[/tabs]

* SOLUTION 1
  * 투포인터: 각 시작지점마다 가능한 길이를 찾음
  * 시간 복잡도: $NlogN$이하로 해야하므로, 투포인터로 찾음
  * 카운팅: 각 과일 개수를 카운팅해줘야 하므로 딕셔너리 하나 사용해주기
