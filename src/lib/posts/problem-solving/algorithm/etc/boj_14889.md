# [백준 : 14889. 스타트와 링크](https://www.acmicpc.net/problem/14889)

## **목표**

> N명의 사람을 두 그룹으로 나눌 때, 두 그룹의 능력치 차이의 최솟값을 구하는 문제.
> `combination -> gospers hack`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
N = int(input())
R = N//2
arr = [list(map(int,input().split())) for _ in range(N)]

answer = float('inf')

x = (1<<R)-1
while x < (1<<N):

    # devide group
    selects = [[],[]]
    for i in range(N):
        selects[x&(1<<i)!=0].append(i)
    
    # cal score
    scores = [0,0]
    for team in range(2):
        for idx,t1 in enumerate(selects[team]):
            for t2 in selects[team][idx:]:
                scores[team] += arr[t1][t2] + arr[t2][t1]
    answer = min(answer, abs(scores[0]-scores[1]))
    
    # next comb
    nx = (x | (x - 1)) + 1
    x = (nx | ((nx&-nx) // (x&-x)) >> 1) - 1

print(answer)
```

* SOLUTION 1
  * 비트마스킹: combination -> gospers hack

## **코멘트**

* 두 그룹으로 분할하는 경우에는 확실히 next comb를 gospers hack으로 구현하는게 쉽다.
