# [백준 : 2632. 피자판매](https://www.acmicpc.net/problem/2632)

## **목표**

> 두 종류의 피자에서 연속된 조각들을 선택하여 주문한 크기의 피자를 만들 수 있는 방법의 수를 구하는 문제.
> `각 피자가 최대 1000조각으로 나누어짐. 연속된 피자 조각으로 만들어지는 피자 size들을 모두 저장함. 정렬 후 이분탐색으로 $NlogN$으로 풀이`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
from collections import defaultdict as dd
import sys
input = lambda : sys.stdin.readline().rstrip()

size = int(input())
m,n = map(int,input().split())

def pizza(p):
    T = [int(input())]
    for _ in range(p-1):
        T.append(T[-1]+int(input()))
    return T
A = pizza(m)
B = pizza(n)

def pizza_comb(T):
    comb = dd(int)
    total = T[-1]
    tl = len(T)
    for i in range(tl): # 피벗
        for j in range(1,tl): # 조각 연속
            if i+j >= tl:
                comb[T[(i+j)%tl] + total - T[i]] += 1
            else:
                comb[T[i+j]-T[i]] += 1
    comb[total] = 1
    comb = list(comb.items())
    comb.sort()
    return comb
        
Acomb = pizza_comb(A)
Acomb = [(0,1)] + Acomb
Bcomb = pizza_comb(B)

bl = len(Bcomb)
answer = 0
for a,count in Acomb:
    goal = size-a
    if goal == 0:
        answer += count
    elif goal > 0:
        l,r = 0,bl -1
        find = False
        while l <= r:
            m = l + (r-l)//2
            if Bcomb[m][0] == goal:
                find = True
                break
            elif Bcomb[m][0] < goal:
                l = m+1
            else:
                r = m-1
        if find:
            answer += count * Bcomb[m][1]
print(answer)
```

* SOLUTION 1
  * 누적합: 피자 1개의 크기는 별로 중요하지 않다. 바로 누적합으로 저장 (1개 사이즈는 인접 인덱스에서 빼면 된다)
  * 조합 저장: 어떤 피자 조각 i를 피벗으로 만들고, 크기가 1,2,...,피자 조각 수에 따라서 총 조각 사이즈를 저장함
  * 이분탐색: 정렬 후 이분탐색으로 $NlogN$으로 풀이
