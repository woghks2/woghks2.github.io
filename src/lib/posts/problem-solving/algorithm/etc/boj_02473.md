# [백준 : 2473. 세 용액](https://www.acmicpc.net/problem/2473)

## **목표**

> 세 용액을 섞어서 특성값이 0에 가장 가까운 세 용액을 찾는 문제.
> `정렬 이후 두 용액의 구한 후, 나머지 하나를 이분탐색으로 빠르게 찾기 or 한 피벗의 값을 정해놓고 투포인터 진행`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
import sys

N = int(input())
arr = list(map(int, input().split()))
arr.sort()

temp = sys.maxsize
answer = []
for p in range(N-2):
    l,r = p+1,N-1

    while l < r:
        idx = [p,l,r]
        ph = sum(arr[i] for i in idx)
        if abs(ph) < abs(temp):
            temp = ph
            answer = [arr[i] for i in idx]

        if ph < 0:
            l += 1
        elif ph > 0:
            r -= 1
        else:
            answer = [arr[i] for i in idx]
            break

answer.sort()
print(*answer)
```
