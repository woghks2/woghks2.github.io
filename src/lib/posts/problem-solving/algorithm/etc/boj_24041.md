# [백준 : 24041. 성싶당 밀키트](https://www.acmicpc.net/problem/24041)

## **목표**

> 세균 수가 G 이하가 되는 최대 날짜를 구하는 문제.
> `범위가 2*1e9까지 가능 -> 최대 31회의 탐색으로 최대값 찾기 가능. $31NlogN$으로 풀이가 가능`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
import sys
input = lambda : sys.stdin.readline().rstrip()

def calc(S,L,day):
    return S*max(1,day-L)

def eat(array,day,K):
    
    score = 0
    temp = []
    for S,L,O in array:
        
        if not O: # 필수는 바로 계산
            score += calc(S,L,day)
        else: # 필수 아니면 정보 저장
            temp.append(calc(S,L,day))
        
        # 중간에 세균 수 넘어가면 False
        if score > G:
            return False
    
    # 필수 아닌 재료 중 상위 K개 제거
    temp.sort(reverse=True)
    if score + sum(temp[K:]) > G:
        return False
    return True

N,G,K = map(int,input().split())
infos = [tuple(map(int,input().split())) for _ in range(N)]

l,r = 0,2*(10**9)
while l<=r:
    m = (l+r)//2
    if eat(infos,m,K):
        answer = m
        l = m+1
    else:
        r = m-1
print(answer)
```

  * 시간 복잡도: 범위가 2*1e9까지 가능 -> 최대 31회의 탐색으로 최대값 찾기 가능. $31NlogN$으로 풀이가 가능
