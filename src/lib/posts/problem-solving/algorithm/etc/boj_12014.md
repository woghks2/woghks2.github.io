# [백준 : 12014. 주식](https://www.acmicpc.net/problem/12014)

## **목표**

> 주식 가격의 최장 증가 부분 수열(LIS)의 길이가 K 이상인지 확인하는 문제.
> `LIS 길이가 K 이상이 되면 1, 아니면 0`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
import sys
input = sys.stdin.readline

N = int(input())
LIS = []
for val in map(int,input().split()):

    if not LIS or val > LIS[-1]:
        LIS.append(val)
        continue

    l,r = -1,len(LIS)
    while l+1<r:
        m = (l+r)//2
        if LIS[m] < val:
            l = m
        else:
            r = m

    if r == len(LIS):
        LIS.append(val)
    else:
        LIS[r] = val

print(len(LIS))
```
