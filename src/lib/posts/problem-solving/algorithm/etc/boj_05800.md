# [백준 : 5800. 성적 통계](https://www.acmicpc.net/problem/5800)

## **목표**

> 각 반의 성적 통계(최댓값, 최솟값, 최대 간격)를 구하는 문제.
> `입력 후, 정렬 + 순회`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
for i in range(int(input())):
    n,*arr = list(map(int,input().split()))
    
    arr.sort()
    print(f"Class {i+1}")
    print(f"Max {arr[-1]}, Min {arr[0]}, Largest gap {max(arr[j+1]-arr[j] for j in range(n-1))}")
```
