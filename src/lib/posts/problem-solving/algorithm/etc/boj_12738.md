# [백준 : 12738. 가장 긴 증가하는 부분 수열 3](https://www.acmicpc.net/problem/12738)

## **목표**

> 수열의 가장 긴 증가하는 부분 수열(LIS)의 길이를 구하는 문제.
> `LIS`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
N = int(input())
arr = list(map(int,input().split()))

LIS = []
for val in arr:
    
    if not LIS or val > LIS[-1]:
        LIS.append(val)
        continue
    
    l,r = -1,len(LIS)
    while l+1<r:
        m = (l+r)//2
        if LIS[m] < val:
            l = m
        else:
            r = m
    LIS[r] = val

print(len(LIS))
```
