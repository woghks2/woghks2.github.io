# [백준 : 12015. 가장 긴 증가하는 부분 수열 2](https://www.acmicpc.net/problem/12015)

## **목표**

> 수열의 가장 긴 증가하는 부분 수열(LIS)의 길이를 구하는 문제.
> `배열 크기가 10^6이라 N^2 DP풀이로는 불가능. LIS의 길이를 구하는 NlogN으로 풀이`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
import sys
input = sys.stdin.readline

N = int(input())
LIS = []
for val in map(int,input().split()):

    if not LIS or val > LIS[-1]:
        LIS.append(val)
        continue

    l,r = -1,len(LIS)
    while l+1<r:
        m = (l+r)//2
        if LIS[m] < val:
            l = m
        else:
            r = m

    if r == len(LIS):
        LIS.append(val)
    else:
        LIS[r] = val

print(len(LIS))
```

[/tabs]

* SOLUTION 1
  * 시간 복잡도: 배열 크기가 10^6이라 N^2 DP풀이로는 불가능
  * 이분탐색: LIS의 길이를 구하는 NlogN으로 풀이
