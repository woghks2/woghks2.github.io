# [백준 : 1182. 부분수열의 합](https://www.acmicpc.net/problem/1182)

## **목표**

> 수열의 부분수열 중 그 합이 S가 되는 경우의 수를 구하는 문제.
> `2^20까지라 그냥 완탐가능해서 완탐으로 풀이`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
N,target = map(int,input().split())
arr = list(map(int,input().split()))

answer = 0
for comb in range(1,1<<N):
    temp = 0
    for i in range(N):
        if comb&(1<<i):
            temp += arr[i]
    if temp == target:
        answer += 1
print(answer)
```
