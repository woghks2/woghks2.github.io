# [백준 : 2003. 수들의 합](https://www.acmicpc.net/problem/2003)

## **목표**

> 수열의 연속된 부분 수열 중 그 합이 M이 되는 경우의 수를 구하는 문제.
> `누적합. 해시 써서 O(N)으로 풀이`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
from collections import defaultdict as dd

N,target = map(int,input().split())
arr = list(map(int,input().split()))

cs = 0
table = dd(int)
table[0] = 1
answer = 0
for a in arr:
    cs += a
    if cs - target in table:
        answer += table[cs-target]
    table[cs] += 1
print(answer)
```

[/tabs]

* SOLUTION 1
  * 누적합: 누적합
  * 해시 사용: 입력이 10000이라 N^2도 될 줄 알았는데, 숫자가 커서 그런가 TLE. 해시 써서 O(N)으로 풀이
