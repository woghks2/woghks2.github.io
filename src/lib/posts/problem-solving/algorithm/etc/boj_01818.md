# [백준 : 1818. 책정리](https://www.acmicpc.net/problem/1818)

## **목표**

> 책을 번호 순서대로 정렬하기 위해 필요한 최소 이동 횟수를 구하는 문제.
> `LIS를 구한 후, 빼주기`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
import sys
input = lambda : sys.stdin.readline().strip()

N = int(input())
arr = list(map(int,input().split()))

LIS = []
for val in arr:
    
    if not LIS or val > LIS[-1]:
        LIS.append(val)
        continue
    
    l,r = -1,len(LIS)
    while l+1<r:
        m = (l+r)//2
        if LIS[m] < val:
            l = m
        else:
            r = m
    LIS[r] = val

print(N-len(LIS))
```
