# [백준 : 1736. 쓰레기 치우기](https://www.acmicpc.net/problem/1736)

## **목표**

> 로봇이 오른쪽과 아래쪽으로만 이동할 수 있을 때, 모든 쓰레기를 수거하기 위해 필요한 최소 로봇의 수를 구하는 문제.
> `오른쪽, 아래쪽으로만 이동이 가능함. (x,y)에서 쓰레기를 주웠으면 (x,y)좌표보다 같거나 큰 위치의 쓰레기만 주울 수 있음`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
from collections import deque
import sys

input = lambda :sys.stdin.readline().rstrip()

Y,X = map(int,input().split())
arr = [tuple(map(int,input().split())) for _ in range(Y)]

trash = [(x,y) for y in range(Y) for x in range(X) if arr[y][x]]
trash = deque(trash)

answer = 0
while trash:
    x,y = trash.popleft()
    answer += 1
    temp = set()
    for idx,(nx,ny) in enumerate(trash):
        if x<=nx and y<=ny:
            x,y = nx,ny
            temp.add(idx)
    trash = deque(trash[i] for i in range(len(trash)) if i not in temp)
print(answer)
```

[/tabs]

* SOLUTION 1
  * 이동 제약: 오른쪽, 아래쪽으로만 이동이 가능함
  * 쓰레기 수거: (x,y)에서 쓰레기를 주웠으면 (x,y)좌표보다 같거나 큰 위치의 쓰레기만 주울 수 있음
  * 그리디 접근: 가장 먼저 발견하는 쓰레기의 좌표를 (x,y)로 두고, 주웠던 쓰레기를 기억하기 위해 set에 저장함

## **코멘트**

* 2차원으로 바뀌었을 뿐, 1차원으로 flatten 시키면 $1<=N<10000$인 문제라서 $O(N^2)$로 풀이.
* 2차원 array를 1차원으로 flatten 하는 과정에서 쓰레기만 추출하면 $O(N^2)$를 많이 줄일 수 있다고 생각했는데, 큰 차이가 없는 듯 하다.
