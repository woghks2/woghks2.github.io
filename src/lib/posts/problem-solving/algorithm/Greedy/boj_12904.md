# [백준 : 12904. A와 B](https://www.acmicpc.net/problem/12904)

## **목표**

> 문자열 S를 T로 변환할 수 있는지 확인하는 문제. 'A'를 뒤에 추가하거나 문자열을 뒤집고 'B'를 뒤에 추가하는 연산만 가능함.
> `start to end로 BFS처럼 진행하면 $2^1000$이라서 메모리 초과. 반대로 end to start로 진행하면, 선택지는 하나밖에 없음`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
start = input()
end = input()

answer = 0
while True:
    
    # 문자열 둘이 같아졌으면 탈출
    if start == end:
        answer = 1
        break
    
    # end를 계속 제거했음에도 불구하고, start를 못찾은 경우 탈출
    if len(start) > len(end):
        answer = 0
        break
    
    # 마지막이 A이면 맨 뒤 제거
    if end[-1] == 'A':
        end = end[:-1]
    # 마지막이 B이면 맨 뒤 제거 후 뒤집기.
    else:
        end = end[:-1]
        end = end[::-1]
print(answer)
```

[/tabs]

* SOLUTION 1
  * 역방향 접근: 반대로 end to start로 진행하면, 선택지는 하나밖에 없음
  * 마지막 문자 처리: 마지막이 A이면 A 제거. 마지막이 B이면 B 제거하고 뒤집기
  * 문자열 제거: 계속 문자열을 제거하면서 start 문자가 나오면 가능, 아니면 불가능
