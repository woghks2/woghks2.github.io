# [백준 : 1715. 카드 정렬하기](https://www.acmicpc.net/problem/1715)

## **목표**

> 여러 묶음의 카드를 하나로 합칠 때, 비교 횟수의 최솟값을 구하는 문제.
> `힙에서 가장 작은 원소 2개를 뽑아서 더한 후, 다시 힙에 넣어주면 됨. 힙의 길이가 1이 될 때 까지 반복`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
import heapq as hq
import sys

input = lambda : sys.stdin.readline().strip()

heap = [int(input()) for _ in range(int(input()))]
hq.heapify(heap)

answer = 0
while len(heap) > 1:
    temp = 0
    for _ in range(2):
        temp += hq.heappop(heap)
    answer += temp
    hq.heappush(heap,temp)
print(answer)
```

[/tabs]

* SOLUTION 1
  * 그리디 접근: 힙에서 가장 작은 원소 2개를 뽑아서 더한 후, 다시 힙에 넣어주면 됨
  * 반복: 힙의 길이가 1이 될 때 까지 반복
