# [백준 : 1374. 강의실](https://www.acmicpc.net/problem/1374)

## **목표**

> 모든 강의를 진행하기 위해 필요한 최소 강의실 개수를 구하는 문제.
> `시작시간 가장 빠른거 부터 뽑기. 시작 시간이 같으면, 빨리 끝나는 강의일수록 다음 강의실을 안 쓸 수 있음`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
import heapq as hq
import sys

input = lambda : sys.stdin.readline().strip()

N = int(input())
arr = [tuple(map(int,input().split())) for _ in range(N)]
arr.sort(key = lambda x : (x[1],x[2]))

heap = []
hq.heappush(heap,arr[0][2])

answer = 1
count = 1
for i in range(1,N):
    _,s,e = arr[i]

    if heap[0] <= s:
        hq.heappop(heap)
        count -= 1

    hq.heappush(heap,e)
    count += 1
    answer = max(answer,count)

print(answer)
```

### **Python (Alternative)**

[tabs: Solution 2]

```python
import heapq as hq

N = int(input())
heap = []
for _ in range(N):
    _,s,e = map(int,input().split())
    hq.heappush(heap,(s,-e))
    
temp_heap = []
answer = 0
while heap:
    s,ne = hq.heappop(heap)
    e = -ne

    if temp_heap and temp_heap[0] <= s:
        hq.heappop(temp_heap)

    hq.heappush(temp_heap,e)
    answer = max(answer,len(temp_heap))

print(answer)
```

[/tabs]

* SOLUTION 1
  * 정렬 + 힙: 시작시간 가장 빠른거 부터 뽑기. 시작 시간이 같으면, 빨리 끝나는 강의일수록 다음 강의실을 안 쓸 수 있음

* SOLUTION 2
  * 힙 + temp 힙: 메모리는 덜 쓰는데, 트리 구조가 계속 변경돼서 시간이 오래걸림
