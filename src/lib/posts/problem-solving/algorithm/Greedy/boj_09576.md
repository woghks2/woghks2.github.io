# [백준 : 9576. 책 나눠주기](https://www.acmicpc.net/problem/9576)

## **목표**

> 각 학생이 원하는 책의 범위가 주어질 때, 가장 많은 학생에게 책을 나눠줄 수 있는 경우의 수를 구하는 문제.
> `구간의 맨 앞 요구부터 책을 나눠줌. a<b 이므로 구간이 끝나는 b 위주로 정렬`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
import sys
input = lambda : sys.stdin.readline().rstrip()

T = int(input())
for _ in range(T):
    
    N,M = map(int,input().split())
    
    # 입력 받아서, 끝 구간을 기준으로 정렬한다. 피벗을 앞으로 정한거니까 구간이 빨리 끝나는 사람부터 처리하기
    demands = [list(map(int,input().split())) for _ in range(M)]
    demands.sort(key=lambda x: x[1])
    
    books = [True]*(N+1)
    answer = 0
    for s,e in demands:
        
        # 처음 찾은 책 위치 idx
        idx = 0
        for i in range(s,e+1):
            if books[i]:
                idx = i
                break

        # 나눠주고 방문처리
        if idx:
            books[idx] = False
            answer += 1
    print(answer)
```
