# [백준 : 1405. 미친 로봇](https://www.acmicpc.net/problem/1405)

## **목표**

> 로봇이 동서남북으로 이동할 때, 같은 칸을 다시 방문하지 않고 N번 이동하는 확률을 구하는 문제.
> `백트래킹을 활용하여 방문하지 않은 칸으로만 이동하는 경우의 확률 합산`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
temp = list(map(int, input().split()))
n,prob = temp[0],list(map(lambda x: x/100, temp[1:]))

visit = [[False]*29 for _ in range(29)]
visit[14][14] = True

step = [(1,0),(-1,0),(0,1),(0,-1)]
count = 0

def dfs(x,y,t,p):
    
    global count
    
    if t == n:
        count += p
        return

    for i in range(4):
        dx,dy = step[i]
        nx,ny = x+dx, y+dy

        if not visit[ny][nx]:
            visit[ny][nx] = True
            dfs(nx,ny,t+1,p*prob[i])
            visit[ny][nx] = False

dfs(14,14,0,1.0)
print(count)
```

[/tabs]

* SOLUTION 1
  * 백트래킹: 4^14 = 약 250만 탐색 경우의 수이므로 가지치기 필수
  * 방문 처리: 같은 칸을 다시 방문하지 않도록 visit 배열로 체크
  * 확률 계산: 각 경로의 확률을 누적하여 최종 확률 합산

## **코멘트**

* 백트래킹 기본
* 다시 풀어봤는데 set 이용해서 방문처리 했는데 map size가 크지 않아서 훨씬 느려지긴 했음
* set이랑 dict은 웬만하면 피하자
  * 케이스 마다 다르지만 빈 테이블이 많거나 다차원 리스트를 쓰는 경우에는 효율이 나쁘지 않다.
