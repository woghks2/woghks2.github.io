# [백준 : 1749. 점수따먹기](https://www.acmicpc.net/problem/1749)

## **목표**

> 2D 배열에서 모든 가능한 직사각형 영역의 합 중 최댓값을 구하는 문제.
> `누적합을 활용하여 O(N^4)를 O(N^2)로 최적화`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
import sys
input = lambda : sys.stdin.readline().rstrip()
 
h,w = map(int,input().split())
arr = [list(map(int,input().split())) for _ in range(h)]

# 누적합 계산
cum = [[0]*(w+1) for _ in range(h+1)]
for i in range(h):
    for j in range(w):
        cum[i+1][j+1] = arr[i][j]+cum[i][j+1]+cum[i+1][j]-cum[i][j]

# 가장 큰 점수가 필요하기에 -inf에서 시작하기
answer = -1e9
for y1 in range(1,h+1):
    for x1 in range(1,w+1):
        for y2 in range(y1,h+1):
            for x2 in range(x1,w+1):
                temp = (cum[y2][x2]-cum[y2][x1-1])-(cum[y1-1][x2]-cum[y1-1][x1-1])
                answer = max(answer,temp)
print(answer)
```

[/tabs]

* SOLUTION 1
  * 누적합: 각 행렬에서 여러 번 반복되는 합을 처리하여 속도 효율성 향상
  * 완전 탐색: 최대 200*200 배열에서 모든 직사각형 영역 탐색
  * 시간 복잡도: O(N^2 * M^2)를 누적합으로 최적화
