# [백준 : 1238. 파티](https://www.acmicpc.net/problem/1238)

## **목표**

> 각 노드에서 목적지까지 가고 돌아오는 최단 거리의 최대값을 구하는 문제.
> `모든 노드에 대해서 다익스트라 돌려서 걸리는 시간 얻기`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
import heapq as hq
import sys

input = lambda : sys.stdin.readline().rstrip()
INF = float('inf')

N,M,X = map(int,input().split())
G = [[] for _ in range(N+1)]
for _ in range(M):
    a,b,cost = map(int,input().split())
    G[a].append((b,cost))

def di(x):
    V = [INF]*(N+1)
    V[x] = 0
    heap = [(0,x)]
    
    while heap:
        t,x = hq.heappop(heap)

        if t>V[x]:
            continue

        for nx,cost in G[x]:
            nt = t+cost
            if nt < V[nx]:
                hq.heappush(heap,(nt,nx))
                V[nx] = nt
    return V

dist = [di(i) for i in range(N+1)]
answer = [dist[i][X]+dist[X][i] for i in range(1,N+1)]
print(max(answer))
```
