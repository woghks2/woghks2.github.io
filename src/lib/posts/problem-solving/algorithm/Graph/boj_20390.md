# [백준 : 20390. 완전그래프의 최소 스패닝 트리](https://www.acmicpc.net/problem/20390)

## **목표**

> 완전 그래프에서 MST를 구하는 문제. 간선 가중치는 수식으로 주어짐.
> `메모리 제한 때문에 힙 쓰는 방식 대신 O(NlogN) ~ O(N^2)으로 풀이`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
import sys

input = sys.stdin.readline
INF = float('inf')

N = int(input())
A,B,C,D = map(int,input().split())
X = list(map(int,input().split()))


# MST seed : node 0
V = [False]*N
dist = [INF]*N
dist[0] = 0
answer = 0
for _ in range(N):

    # 3. 현재까지 MST 중 거리가 가장 작은 간선 선택하기
    x = -1
    cost = INF
    for i in range(N):
        if not V[i] and dist[i] < cost:
            cost = dist[i]
            x = i
    
    # 1. MST 연결 후, 간선 추가하기
    V[x] = True
    answer += cost
    
    # 2. node 0에서 시작해서
    for nx in range(N):
        if not V[nx]:
            ncost = ((X[min(x,nx)]*A+X[max(x,nx)]*B)%C)^D
            if ncost < dist[nx]:
                dist[nx] = ncost

print(answer)
```

[/tabs]

* SOLUTION 1
  * 프림 알고리즘: 메모리 제한 때문에 힙 쓰는 방식 대신 $O(N^2)$에 가까운 프림 알고리즘으로 풀이.
  * 접근 방법: 현재 스패닝 트리에서 가장 가까운 거리를 dist에 업데이트한다. 현재 스패닝 트리와 거리가 가장 가까운 간선을 선택한다.
