# [SWEA : 3124. 최소 스패닝 트리](https://swexpertacademy.com/main/code/problem/problemDetail.do?contestProbId=AV_mSnmKUckDFAWb)

## **목표**

> 주어진 그래프에서 모든 정점을 연결하는 최소 스패닝 트리의 가중치 합을 구하는 문제.
> `크루스칼 기본. 정렬 후 N-1개 간선 연결하면 탈출하기`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
TC = int(input())
 
def find(x):
    if x != P[x]:
        P[x] = find(P[x])
    return P[x]
 
for tc in range(1,TC+1):
 
    N,M = map(int,input().split())
 
    G = [tuple(map(int,input().split())) for _ in range(M)]
 
    P = [i for i in range(N+1)]
 
    G.sort(key=lambda x:x[2])
 
    count = 0
    answer = 0
    for a,b,cost in G:
         
        pa,pb = find(a), find(b)
 
        if pa != pb:
            P[max(pa,pb)] = min(pa,pb)
            count += 1
            answer += cost
 
        if count == N-1:
            break
     
    print(f"#{tc} {answer}")
```
