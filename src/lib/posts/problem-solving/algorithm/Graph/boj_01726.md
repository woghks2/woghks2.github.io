# [백준 : 1726. 로봇](https://www.acmicpc.net/problem/1726)

## **목표**

> 로봇이 목적지까지 도달하는 최소 시간을 구하는 문제. 한 번에 1~3칸까지 이동 가능.
> `H * W * 4방향으로 visit 배열 생성하기`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
from collections import deque
import sys
input = lambda : sys.stdin.readline().rstrip()

H,W = map(int,input().split())
arr = [list(map(int,input().split())) for _ in range(H)]

# 인덱스 1씩 빼주기
sy,sx,sd = map(lambda x:int(x)-1,input().split())
ey,ex,ed = map(lambda x:int(x)-1,input().split())

# 0123(동서남북) -> 0123(동남서북)
dire = [(1,0),(0,1),(-1,0),(0,-1)]
cvt_dire = {0:0,1:2,2:1,3:3}
inside = lambda x,y: 0<=x<W and 0<=y<H

V = [[[-1]*W for _ in range(H)] for _ in range(4)]
V[cvt_dire[sd]][sy][sx] = 0

Q = deque([(sx,sy,cvt_dire[sd])])
while Q:
    
    x,y,d = Q.popleft()
    
    # 방향 바꾸는 경우 : 방문하지 않았으면 방문
    for i in [1,-1]:
        nd = (d+i)%4
        if V[nd][y][x] == -1:
            V[nd][y][x] = V[d][y][x] + 1
            Q.append((x,y,nd))
                    
    # 전진하는 경우 : 장애물만 없으면 된다. 장애물 만나면 break
    dx,dy = dire[d]
    for k in range(1,4):
        nx,ny = x+dx*k, y+dy*k
        if not inside(nx,ny) or arr[ny][nx]:
            break
        if V[d][ny][nx] == -1:
            V[d][ny][nx] = V[d][y][x] + 1
            Q.append((nx,ny,d))

print(V[cvt_dire[ed]][ey][ex])
```

[/tabs]

* SOLUTION 1
  * BFS: H * W * 4방향으로 visit 배열 생성하기
  * 접근 방법: 방향을 회전하거나, 전진하는 경우를 모두 고려하여 BFS로 탐색
