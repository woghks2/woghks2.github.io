# [백준 : 11779. 최소비용 구하기 2](https://www.acmicpc.net/problem/11779)

## **목표**

> 시작점에서 도착점까지의 최단 경로와 경로를 출력하는 문제.
> `최소비용 구하기 1916 이랑 같은 문제. 다익스트라 + 역추적`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
import heapq as hq
import sys
input = lambda : sys.stdin.readline().rstrip()

N = int(input())
M = int(input())

G = [[] for _ in range(N+1)]
for _ in range(M):
    a,b,cost = map(int,input().split())
    G[a].append((b,cost))

start,end = map(int,input().split())

V = [[float('inf'),None]]*(N+1)
V[start] = [0,-1] 
heap = [(0,start)]
while heap:
    t,x = hq.heappop(heap)

    if t > V[x][0]:
        continue
    for nx, cost in G[x]:
        nt = t + cost
        if nt < V[nx][0]:
            V[nx] = [nt,x]
            hq.heappush(heap,(nt,nx))

path = [end]
while True:
    px = V[path[-1]][1]
    if px == -1:
        break
    else:
        path.append(px)
print(V[end][0])
print(len(path))
print(*path[::-1])
```
