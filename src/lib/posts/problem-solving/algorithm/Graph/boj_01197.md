# [백준 : 1197. 최소 스패닝 트리](https://www.acmicpc.net/problem/1197)

## **목표**

> 그래프의 최소 스패닝 트리의 가중치 합을 구하는 문제.
> `유니온 파인드로 구현. 시간 줄이고 싶으면 모든 노드가 연결되면 탈출하는 방식으로 풀이`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
import sys
sys.setrecursionlimit(10**6) 
input = lambda : sys.stdin.readline().rstrip()

V,E = map(int,input().split())
G = [list(map(int,input().split())) for _ in range(E)]
G.sort(key=lambda x:x[2])

P = [i for i in range(V+1)]

def find(a):
    if P[a] != a:
        P[a] = find(P[a])
    return P[a]

def union(pa,pb):
    P[max(pa,pb)] = min(pa,pb)

answer = 0
for (a,b,cost) in G:
    pa,pb = find(a),find(b)
    if pa != pb:
        union(pa,pb)
        answer += cost

print(answer)
```

* SOLUTION 1
  * 유니온-파인드: 유니온 파인드로 구현
  * 최적화: 시간 줄이고 싶으면 모든 노드가 연결되면 탈출하는 방식으로 풀이. 루프 방지를 위해서 항상 번호가 작은 노드를 루트로 함
