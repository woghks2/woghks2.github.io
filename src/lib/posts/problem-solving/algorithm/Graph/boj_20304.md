# [백준 : 20304. 비밀번호 제작](https://www.acmicpc.net/problem/20304)

## **목표**

> 해밍 거리가 최대가 되는 비밀번호를 찾는 문제.
> `BFS. 비트연산으로 해밍거리 1인거부터 차례로 이동하면 OK`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
from collections import deque

N = int(input())
M = int(input())
arr = list(map(int,input().split()))

V = [-1]*(N+1)
for a in arr:
    V[a] = 0
leng = len(bin(N))-2

Q = deque(list(zip(arr,[0]*N)))
while Q:
    x,t = Q.popleft()
    for l in range(leng):
        nx = x^(1<<l)
        if 0<=nx<=N and V[nx] == -1:
            V[nx] = t+1
            Q.append((nx,t+1))
print(max(V))
```

  * 접근 방법: 비트연산으로 해밍거리 1인거부터 차례로 이동하면 OK
