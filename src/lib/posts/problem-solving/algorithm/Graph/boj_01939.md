# [백준 : 1939. 중량제한](https://www.acmicpc.net/problem/1939)

## **목표**

> 공장에서 물품을 수송할 때, 한 번에 옮길 수 있는 물품들의 중량의 최댓값을 구하는 문제.
> `최대힙 또는 BFS + 이분탐색. 현재까지 지나온 중량제한을 힙에 넣고 (최대힙으로), 중량 제한이 가장 큰 다리부터 건너 도착지에 가장 먼저 도달하는 것이 정답`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
import heapq as hq
import sys
input = lambda: sys.stdin.readline().rstrip()

n,m = map(int,input().split())
graph = {i: {} for i in range(1,n+1)}

for _ in range(m):
    a,b,limit = map(int,input().split())
    if b in graph[a]:
        graph[a][b] = max(graph[a][b],limit)
        graph[b][a] = max(graph[b][a],limit)
    else:
        graph[a][b] = limit
        graph[b][a] = limit

start,end = map(int,input().split())

q = []
visit = [0]*(n+1)
visit[start] = float('inf')

for nx in graph[start]:
    limit = graph[start][nx]
    hq.heappush(q,(-limit,nx))
    visit[nx] = limit

while q:
    limit,x = hq.heappop(q)
    limit = -limit
    
    if x == end:
        print(limit)
        break
        
    for nx in graph[x]:
        nlimit = min(limit,graph[x][nx])
        if visit[nx] < nlimit:
            visit[nx] = nlimit
            hq.heappush(q,(-nlimit,nx))
```

[tabs: Solution 2]

```python
from collections import deque, defaultdict as dd
import sys
input = lambda : sys.stdin.readline().rstrip()

N,M = map(int,input().split())

G = dd(lambda : dd(int))
for _ in range(M):
    a,b,new_limit = map(int,input().split())
    limit = G[a][b]
    G[a][b] = max(limit,new_limit)
    G[b][a] = max(limit,new_limit)

start,end = map(int,input().split())

def BFS(s,e,w):

    Q = deque([s])
    V = set([s])

    while Q:
        x = Q.popleft()

        if x==e:
            return True

        for nx,limit in G[x].items():
            if nx not in V and w<=limit:
                V.add(nx)
                Q.append(nx)
    return False

answer = 0
l,r = 1,10**9
while l<=r:
    m = (l+r)//2

    if BFS(start,end,m):
        l = m+1
        answer = max(answer,m)
    else:
        r = m-1

print(answer)
```

* SOLUTION 1
  * 최대힙: 시작 노드와 연결된 섬들의 중량제한과 노드를 큐에 넣는다. 값이 가장 큰 다리의 중량을 찾아야하니 최대힙 사용. (-중량제한,노드)를 큐에 넣는다.
* SOLUTION 2
  * BFS + 이분탐색: 중량 제한이 $10^9$이므로 BFS 30번으로 탐색이 가능하다. 나르는 무게 w를 정하고 s -> e가 가능한지 T/F로 판단하여, 이분탐색을 진행한다.
