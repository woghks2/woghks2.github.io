# [SWEA : 3289. 서로소 집합](https://swexpertacademy.com/main/code/problem/problemDetail.do?contestProbId=AWBJKA6qr2oDFAWr)

## **목표**

> 서로소 집합을 관리하는 문제. 두 원소가 같은 집합에 속하는지 확인하고, 다른 집합이면 합치는 연산을 수행함.
> `유니온 파인드. 쿼리가 많아서 String Builder 효율이 좋음`

## **문제 풀이**

### **Java**

[tabs: Solution 1]

```java
import java.io.*;
import java.util.*;
 
public class Solution{
 
    static int N,M;
    static int[] P;
 
    public static int find(int x) {
        if (P[x] != x) {
            P[x] = find(P[x]);
        }
        return P[x];
    }
    public static void main(String[] args) throws Exception {
 
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st;
 
        // test case
        StringBuilder answer = new StringBuilder();
        int TC = Integer.parseInt(br.readLine());
        for (int tc = 1; tc <= TC; tc++) {
             
            answer.append("#").append(tc).append(" ");
            // read input
            st = new StringTokenizer(br.readLine());
            N = Integer.parseInt(st.nextToken());
            M = Integer.parseInt(st.nextToken());
 
            // init parent
            P = new int[N+1];
            for (int i=0; i<N+1; i++) {
                P[i] = i;
            }
 
            // query
            for (int i=0; i<M; i++) {
                st = new StringTokenizer(br.readLine());
                int cmd = Integer.parseInt(st.nextToken());
                int a = Integer.parseInt(st.nextToken());
                int b = Integer.parseInt(st.nextToken());
                 
                int pa = find(a), pb = find(b);
                if (cmd == 0) {
                    if (pa != pb) {
                        P[Math.max(pa,pb)] = Math.min(pa,pb);
                    }
                } else {
                    if (pa != pb) {
                        answer.append("0");
                    } else {
                        answer.append("1");
                    }
                }
            }
            answer.append("\n");
 
            // output
        }
        System.out.println(answer.toString());
    }
}
```
