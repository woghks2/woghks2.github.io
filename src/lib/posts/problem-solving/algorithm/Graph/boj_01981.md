# [백준 : 1981. 배열에서 이동](https://www.acmicpc.net/problem/1981)

## **목표**

> 배열의 시작점에서 끝점까지 이동할 때, 거쳐가는 숫자의 최대값과 최소값의 차이를 최소화하는 문제.
> `배열에서 이동하는 문제. BFS + 이분탐색으로 풀이. window를 [a,b]로 잡고, 도달할 수 있는지 없는지 풀이`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
from collections import deque
import sys
input = sys.stdin.readline
inside = lambda x,y : 0<=x<N and 0<=y<N
dire = [(1,0),(0,1),(-1,0),(0,-1)]

N = int(input())
arr = [list(map(int,input().split())) for _ in range(N)]

def bfs(a,b):
    if not (a<=arr[0][0]<=b):
        return False
    
    Q = deque([(0,0)])
    V = [[False]*N for _ in range(N)]
    V[0][0] = True
    
    while Q:
        x,y = Q.popleft()
        if (x,y) == (N-1,N-1):
            return True
        for dx,dy in dire:
            nx,ny = x+dx,y+dy
            if inside(nx,ny) and a<=arr[ny][nx]<=b and (not V[ny][nx]):
                V[ny][nx] = True
                Q.append((nx,ny))
    return False

l,r = 0,200
answer = 200
while l <= r:
    limit = (l+r)//2
    possible = False
    
    for a in range(201-limit):
        if bfs(a,a+limit):
            possible = True
            break
    
    if possible:
        answer = limit
        r = limit-1
    else:
        l = limit+1

print(answer)
```

* SOLUTION 1
  * BFS + 이분탐색: BFS + 이분탐색으로 풀이
  * 윈도우 슬라이딩: window를 [a,b]로 잡고, 도달할 수 있는지 없는지 풀이. limit = b-a라고 했을 때 하나라도 성공하면 그 limit는 성공하고 다음 이분탐색 범위로 풀이
