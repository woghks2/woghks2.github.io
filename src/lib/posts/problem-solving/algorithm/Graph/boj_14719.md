# [백준 : 14719. 빗물](https://www.acmicpc.net/problem/14719)

## **목표**

> 블록 사이에 고인 빗물의 양을 구하는 문제.
> `스택/그리디 풀이. 왼쪽 벽이 아닌 높이에서 출발해서 같은 높이의 벽을 세워줌`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
import sys

input = sys.stdin.readline

H, W = map(int, input().split())
blocks = list(map(int, input().split()))

stack = []
water = 0

for i in range(W):
    while stack and blocks[stack[-1]] < blocks[i]:  # 현재 블록이 스택의 top보다 높은 경우
        bottom = stack.pop()
        
        if not stack:  # 스택이 비면 더 이상 담을 수 없음
            break
        
        left = stack[-1]  # 왼쪽 벽
        height = min(blocks[left], blocks[i]) - blocks[bottom]  # 물 높이 계산
        width = i - left - 1  # 물이 고이는 너비

        water += height * width  # 물 저장량 추가

    stack.append(i)  # 현재 블록을 스택에 추가

print(water)
```

[/tabs]

* SOLUTION 1
  * 스택/그리디: 스택을 이용한 그리디 풀이
  * 접근 방법: 왼쪽 벽이 아닌 높이에서 출발해서 같은 높이의 벽을 세워줌. 마찬가지로 오른쪽 벽이 아닌 높이에서 출발해서 같은 높이의 벽을 세워줌
