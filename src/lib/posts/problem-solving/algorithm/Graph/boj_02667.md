# [백준 : 2667. 단지번호붙이기](https://www.acmicpc.net/problem/2667)

## **목표**

> 지도를 탐색하여 단지 수를 출력하고, 각 단지에 속하는 집의 수를 오름차순으로 정렬하여 출력하는 문제.
> `BFS/DFS. 노드를 기준으로 방문 및 조건 검사를 해주면 메인 BFS가 훨씬 가벼워진다`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
from collections import deque
from dataclasses import dataclass

dires = [(1,0),(0,1),(-1,0),(0,-1)]

@dataclass(frozen=True)
class Vertex:
    x: int
    y: int

    @property
    def next_steps(self):
        return [Vertex(self.x+dx,self.y+dy) for dx,dy in dires]
    
    def is_inside(self):
        return 0<=self.x<N and 0<=self.y<N

    def is_visited(self):
        return V[self.y][self.x]
    
    def is_valid(self):
        return self.is_inside() and arr[self.y][self.x] and not self.is_visited()
    
    def visit(self):
        V[self.y][self.x] = True

def bfs(sv:Vertex, area=1):
    sv.visit()
    Q = deque([sv])
    while Q:
        cv = Q.popleft()
        for nv in cv.next_steps:
            if nv.is_valid():
                nv.visit()
                Q.append(nv)
                area += 1
    return area

N = int(input())
arr = [list(map(int, input())) for _ in range(N)]
V = [[False]*N for _ in range(N)]
areas = [bfs(Vertex(j,i)) for i in range(N) for j in range(N) if arr[i][j] and not V[i][j]]

print(len(areas))
for area in sorted(areas):
    print(area)
```

* SOLUTION 1
  * BFS: BFS를 사용하여 연결된 단지를 찾고, 각 단지의 크기를 구한다.
  * Dataclass: 클래스 좀 익힐겸 데이터 클래스 이용해서 문제 풀이. 노드를 기준으로 방문 및 조건 검사를 해주면 메인 BFS가 훨씬 가벼워진다.
