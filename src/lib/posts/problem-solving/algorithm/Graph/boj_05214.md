# [백준 : 5214. 환승](https://www.acmicpc.net/problem/5214)

## **목표**

> 하이퍼튜브를 이용하여 1번 역에서 N번 역까지 가는데 방문하는 최소 역의 개수를 구하는 문제.
> `하이퍼튜브를 하나의 정점으로 보면, 하이퍼튜브 탑승/하차의 cost가 0/1임을 알 수 있다. 0-1 너비우선 탐색`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
from collections import deque
import sys

input = lambda : sys.stdin.readline().strip()

N,K,M = map(int,input().split())

G = [[[] for _ in range(N)], [[] for _ in range(M)]]
for tube in range(M):
    for x in map(lambda x : int(x)-1, input().split()):
        G[0][x].append(tube)
        G[1][tube].append(x)

V = [[False]*N,[False]*M]
V[0][0] = 1
Q = deque([(0,1,False)])
while Q:
    node,t,in_tube = Q.popleft()
    if not in_tube:
        for tube in G[0][node]:
            if not V[1][tube]:
                V[1][tube] = t
                Q.appendleft((tube,t,True))
    else:
        for station in G[1][node]:
            if not V[0][station]:
                V[0][station] = t+1
                Q.append((station,t+1,False))

print(V[0][-1] if V[0][-1] else -1)
```

[/tabs]

* SOLUTION 1
  * 0-1 BFS: 하이퍼튜브를 하나의 정점으로 보면, 하이퍼튜브 탑승/하차의 cost가 0/1임을 알 수 있다.
  * 구현: 탑승에는 appendleft, 하차에는 append를 사용해서 구현.
