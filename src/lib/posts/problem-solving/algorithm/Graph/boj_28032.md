# [백준 : 28032. Filed Day](https://www.acmicpc.net/problem/28032)

## **목표**

> 각 팀마다 자신과 가장 성향이 반대인 팀(해밍 거리가 먼 팀)과의 거리를 구하는 문제.
> `입력이 커서 O(N^2)로는 불가능. 각 node의 toggle값을 넣고 BFS를 돌리면 해당 노드에서 가장 가까운 거리를 찾고 C에서 빼면 정답을 구할 수 있다`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
from collections import deque

W,H = map(int, input().split())

V = [-1]*(1<<W)
Q = deque()
arr = []
limit = 2**W-1
for _ in range(H):
    string = input()
    x = 0
    for idx,s in enumerate(string):
        x += (s=='G')*(2**idx)
    arr.append(x)
    V[limit-x] = 0
    Q.append(limit-x)

while Q:
    x = Q.popleft()
    for i in range(W):
        nx = x^(1<<i)
        if V[nx] == -1:
            Q.append(nx)
            V[nx] = V[x] + 1

for i in range(H):
    print(W-V[arr[i]])
```

[/tabs]

* SOLUTION 1
  * 비트마스킹 + BFS: 각 node bit로 표현하기. 각 node의 toggle값을 넣고 BFS를 돌리면 해당 노드에서 가장 가까운 거리를 찾고 C에서 빼면 정답을 구할 수 있다.
