# [백준 : 29792. 규칙적인 보스돌이](https://www.acmicpc.net/problem/29792)

## **목표**

> 정해진 시간 동안 보스를 처치하여 얻을 수 있는 최대 메소(점수)를 구하는 문제.
> `각 캐릭터로 BFS를 돌려서 최대 데미지를 구함. 원래는 냅색으로 캐릭당 2중 for문, 총 3중 for문으로 풀 수 있다`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
from collections import deque

N,C,B = map(int,input().split())

dmgs = [int(input()) for _ in range(N)]
dmgs.sort(reverse=True)
boss = [tuple(map(int,input().split())) for _ in range(B)]

def bfs(dmg):

    V = [0]*(B+1)
    Q = deque([(0,900,0)])
    while Q:
        kill,remain,reward = Q.popleft()

        if kill==B:
            continue 

        hp,money = boss[kill]
        Q.append([kill+1,remain,reward])
        
        p,q = divmod(hp,dmg)
        spend = p + (1 if q else 0)
        if remain >= spend:
            Q.append([kill+1,remain-spend,reward+money])
            V[kill+1] = max(V[kill+1], reward+money)
    return max(V)

answer = sum(bfs(dmgs[i]) for i in range(C))
print(answer)
```

[/tabs]

* SOLUTION 1
  * BFS: 각 캐릭터로 BFS를 돌려서 최대 데미지를 구함.
  * 냅색: 원래는 냅색으로 캐릭당 2중 for문, 총 3중 for문으로 풀 수 있다.
