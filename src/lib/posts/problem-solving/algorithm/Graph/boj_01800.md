# [백준 : 1800. 인터넷 설치](https://www.acmicpc.net/problem/1800)

## **목표**

> 최대 K개의 전선을 무료로 설치할 수 있을 때, 설치해야 하는 전선의 최대 비용을 최소화하는 문제.
> `DFS로 node N까지 경로 메모리에 저장한다든가, 탐색을 여러 번 진행하면 TLE 발생. limit원까지 지불할 수 있을 때 node N까지 도달할 수 있냐 없냐를 확인함`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
import heapq as hq
import sys


input = lambda : sys.stdin.readline().strip()
INF = float('inf')

N,P,K = map(int,input().split())

G = [[] for _ in range(N+1)]
for _ in range(P):
    a,b,cost = map(int,input().split())
    G[b].append((a,cost))
    G[a].append((b,cost))

def di(sx,limit):

    PQ = [(0,sx)]
    V = [INF]*(N+1)
    V[sx] = 0

    while PQ:
        cnt,x = hq.heappop(PQ)
        ncnt = cnt + 1

        for nx,cost in G[x]:

            if cost > limit and ncnt < V[nx]:
                V[nx] = ncnt
                hq.heappush(PQ,(ncnt,nx))
            if cost <= limit and cnt < V[nx]:
                V[nx] = cnt
                hq.heappush(PQ,(cnt,nx))

    return V[-1] <= K

answer = INF
l,r = 0,10**6+1
while l<=r:
    m = (l+r)//2
    if di(1,m):
        r = m-1
        answer = m
    else:
        l = m+1

print(answer if answer != INF else -1)
```

[/tabs]

* SOLUTION 1
  * 이분탐색 + 다익스트라: limit원까지 지불할 수 있을 때 node N까지 도달할 수 있냐 없냐를 확인함
  * 접근 방법: 금액 크기가 $10^6$이므로 이분탐색 20번 정도면 풀이가 가능함. $O(20*NlogN)$이고 N이 크지 않아서 시간은 널널하게 풀이가 가능. 이분탐색은 가장 비싼 간선 limit 제한이 걸렸을 때 node N까지 진행이 가능한가를 확인하고, 다익스트라는 N번 노드까지 사용한 전선의 개수를 기록함
