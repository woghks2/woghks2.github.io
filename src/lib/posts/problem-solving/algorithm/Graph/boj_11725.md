# [백준 : 11725. 트리의 부모 찾기](https://www.acmicpc.net/problem/11725)

## **목표**

> 트리의 루트가 1일 때, 각 노드의 부모를 구하는 문제.
> `루트노드부터 BFS 돌려서 각 노드에 부모 노드를 기록하기`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
from collections import deque
import sys
input = lambda : sys.stdin.readline().rstrip()

N = int(input())
G = [[]*(N+1) for _ in range(N+1)]
for _ in range(N-1):
    a,b = map(int,input().split())
    G[a].append(b)
    G[b].append(a)
    
V = [-1]*(N+1)
V[1] = 0
Q = deque([1])
while Q:
    x = Q.popleft()
    for nx in G[x]:
        if V[nx] == -1:
            V[nx] = x
            Q.append(nx)

for p in V[2:]:
    print(p)
```
