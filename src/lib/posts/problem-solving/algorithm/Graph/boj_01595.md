# [백준 : 1595. 북쪽나라의 도로](https://www.acmicpc.net/problem/1595)

## **목표**

> 트리의 지름을 구하는 문제.
> `BFS를 통해서 한 점에서 가장 끝 점으로 간 후 BFS를 돌려줌. 트리의 지름을 구하는 문제와 동일한 발상`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
from collections import deque, defaultdict as dd
import sys
input = lambda: sys.stdin.readline().rstrip()

graphs = dd(list)
while True:
    try:
        a,b,c = map(int,input().split())
        graphs[a].append((b,c))
        graphs[b].append((a,c))
    except:
        break

def bfs(x):
        
    visit = dd(int)
    visit[x] = 0
    q = deque([(x,0)])

    while q:
        x,c = q.popleft()
        for nx,cost in graphs[x]:
            nc = c + cost
            if nx not in visit:
                visit[nx] = nc
                q.append((nx,nc))
    return visit
```
