# [SWEA : 1238. Contact](https://swexpertacademy.com/main/code/problem/problemDetail.do?contestProbId=AV15B1cKAKwCFAYD)

## **목표**

> 연락망에서 시작 지점으로부터 가장 늦게 연락을 받는 사람 중 번호가 가장 큰 사람을 찾는 문제.
> `BFS문제. 인데 유니온 파인드로 풀어보려고 했는데, 둘다보니까 BFS랑 다를바가 없음`

## **문제 풀이**

### **Java**

[tabs: Solution 1]

```java
import java.io.*;
import java.util.*;
 
public class Solution {
 
    static int N, sx;
    static int[] P;
    static int time;
    static int node;
    static ArrayList<ArrayList<Integer>> G;
    static ArrayDeque<int[]> Q;
 
    public static void main(String[] args) throws Exception {
 
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st;
 
        // test case
        int TC = 10;
        int MAX_N = 101;
 
        for (int tc = 1; tc <= TC; tc++) {
 
            // read input
            st = new StringTokenizer(br.readLine());
            N = Integer.parseInt(st.nextToken());
            sx = Integer.parseInt(st.nextToken());
 
            // init parents
            P = new int[MAX_N];
            for (int i = 1; i < MAX_N; i++) {
                P[i] = i;
            }
 
            // init time and node
            time = -1;
            node = -1;
 
            // init graph
            G = new ArrayList<>();
            for (int i = 0; i < MAX_N; i++) {
                G.add(new ArrayList<>());
            }
 
            // read edges
            st = new StringTokenizer(br.readLine());
            for (int i = 0; i < N / 2; i++) {
                int x = Integer.parseInt(st.nextToken());
                int y = Integer.parseInt(st.nextToken());
                G.get(x).add(y);
            }
 
            Q = new ArrayDeque<>();
            Q.offer(new int[] {sx, 0});
 
            while (!Q.isEmpty()) {
                int[] cur = Q.poll();
                int x = cur[0], t = cur[1];
 
                for (int nx : G.get(x)) {
                    if (P[nx] != sx) {
                        P[nx] = sx;
 
                        if (t + 1 > time) {
                            time = t + 1;
                            node = nx;
                        } else if (t + 1 == time && nx > node) {
                            node = nx;
                        }
 
                        Q.offer(new int[] {nx, t + 1});
                    }
                }
            }
            System.out.println("#" + tc + " " + node);
        }
    }
}
```
