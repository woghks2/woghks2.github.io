# [백준 : 7570. 줄 세우기](https://www.acmicpc.net/problem/7570)

## **목표**

> N명의 아이를 번호 순서대로 줄을 세울 때, 최소 몇 명을 이동시켜야 하는지 구하는 문제.
> `1씩 증가하는 LIS를 찾아주고, 전체 길이에서 빼주면 움직일 사람의 수가 나옴`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
from collections import defaultdict as dd

N = int(input())
arr = list(map(int,input().split()))
table = dd(int)
for a in arr:
    table[a] = table[a-1] + 1
print(N-max(table.values()))
```

[/tabs]

* SOLUTION 1
  * LIS: 1씩 증가하는 LIS를 찾아주기
  * 최소 이동: 1씩 증가하는 LIS의 길이를 구한 후, 전체 길이에서 빼주면 움직일 사람의 수가 나옴
