# [백준 : 14238. 출근기록](https://www.acmicpc.net/problem/14238)

## **목표**

> A, B, C로 이루어진 출근 기록을 조건에 맞게 재배열하는 문제.
> `DFS + DP로 상태에 영향을 주는 건 문자열의 맨 뒤 두 자리이므로 이를 기준으로 메모제이션`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
info = {'A':0,'B':0,'C':0}
for s in input():
    info[s] += 1

dp = set()

answer = None

def dfs(a,b,c,string):
    global answer

    if answer is not None: # 정답을 찾은 경우에는 탈출
        return
    
    if (a,b,c,string[-2:]) in dp: # 남은 abc 개수가 같고, 뒤 끝자리가 같으면 같은 상태이므로 중복 탐색 x
        return
    
    if (a,b,c) == (0,0,0): # 모두 출근 가능하면 정답 변경
        answer = string    
        return
    
    if a: # a에는 조건이 없다
        dfs(a-1,b,c,string+'A')
        dp.add((a,b,c,string[-2:]))
    if b: # b에는 맨 뒷자리가 B가 아닌 경우에 탐색
        if not string:
            dfs(a,b-1,c,'B')
            dp.add((a,b,c,string[-2:]))
        elif string and string[-1] != 'B':
            dfs(a,b-1,c,string+'B')
            dp.add((a,b,c,string[-2:]))
    if c: # c에는 뒤 2자리에 C가 없는 경우에 탐색
        if len(string) < 2:
            dfs(a,b,c-1,string+'C')
            dp.add((a,b,c,string[-2:]))
        elif string[-2:] != 'CC' and string[-1] != 'C':
            dfs(a,b,c-1,string+'C')
            dp.add((a,b,c,string[-2:]))

dfs(info['A'],info['B'],info['C'],'')
print(answer if answer else -1)
```

[/tabs]

* SOLUTION 1
  * DFS + DP: 상태에 영향을 주는 건 문자열의 맨 뒤 두 자리
  * 조건: 맨 끝자리에 B가 있으면 다음 B를 추가하는 branch는 탐색하지 못함. 맨 끝 2자리에 C가 포함되어 있으면 다음 C를 추가하는 branch는 탐색하지 못함
