# [백준 : 2253. 점프](https://www.acmicpc.net/problem/2253)

## **목표**

> N개의 돌에서 1번 돌에서 N번 돌까지 점프로 이동하는 최소 점프 횟수를 구하는 문제.
> `전형적인 2차원 DP로 같은 노드 x라도 어떤 속도로 접근했냐에 따라서 다음의 선택지가 바뀌므로 위치 x와 속도 v로 DP 테이블 구성`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
N,M = map(int,input().split())
trap = set(int(input()) for _ in range(M))

inf = float('inf')

# dp[v][x] x번째 위치에 갈 때 속도 v로 갈 경우 최솟값
dp = [[inf]*(N+1) for _ in range(150)] # 가속도가 1인 채로 유지해서 갈 경우 k(k-1)/2 > 10000인 k
dp[0][1] = 0
if 2 not in trap:
    dp[1][2] = 1

for x in range(2,N): # x에
    for v in range(150): # 속도 v로 위치한 말이
        for nv in (v-1,v,v+1): # nv 속도로
            nx = x + nv # nx에 이동하는 경우
            if nx <= N and 1<=nv<150 and nx not in trap: # 돌다리 범위 / 1칸 이상 / 작은 돌멩이 x
                dp[nv][nx] = min(dp[nv][nx],dp[v][x]+1)
                
answer = min(dp[i][-1] for i in range(150))
print(answer if answer != inf else -1)
```

[/tabs]

* SOLUTION 1
  * 2차원 DP: 같은 노드 x라도 어떤 속도로 접근했냐에 따라서 다음의 선택지가 바뀌므로 위치 x와 속도 v로 DP 테이블을 만듦
  * 속도 제한: N = 10000이므로 최대 속도는 약 141. 넉넉잡아서 최대 속도를 150으로 제한
  * 초기화: node 1에는 속력 0으로 접근. node 2가 트랩이 아닌 경우 속도 1로 접근

## **코멘트**
