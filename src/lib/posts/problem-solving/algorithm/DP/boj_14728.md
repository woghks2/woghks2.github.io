# [백준 : 14728. 벼락치기](https://www.acmicpc.net/problem/14728)

## **목표**

> T시간 동안 N개의 문제를 풀어 최대 점수를 얻는 문제.
> `냅색 기본 문제로 상한선이 주어진 무언가가 있을 때 최댓값을 찾는 문제`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
N,T = map(int,input().split())

dp = [[0]*(T+1) for _ in range(N+1)] # T시간 썼을 때 얻을 수 있는 점수 최대값
for i in range(1,N+1):
    t,s = map(int,input().split())
    for j in range(T+1):
        if j >= t:
            # max(현재 문제를 풀지 않는 경우 / 현재 문제를 푼 경우)
            dp[i][j] = max(dp[i-1][j],dp[i-1][j-t]+s)
        else:
            # 문제를 풀지 못하는 경우
            dp[i][j] = dp[i-1][j]
print(max(dp[-1]))
```

[/tabs]

* SOLUTION 1
  * 냅색 기본문제: 상한선이 주어진 무언가가 있을 때 최댓값을 찾는 문제
  * 상태 업데이트: 각 상태를 node로 표현해서 바텀업으로 표현하면 쉽게 풀 수 있음

## **코멘트**

* 각 상태를 node로 표현해서 바텀업으로 표현하면 쉽게 풀 수 있다.
* 질문 게시판에도 나와있지만, 문제를 풀지 못하는 경우에도 업데이트를 해줘야한다.
