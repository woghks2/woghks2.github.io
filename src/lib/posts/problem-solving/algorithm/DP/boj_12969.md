# [백준 : 12969. ABC](https://www.acmicpc.net/problem/12969)

## **목표**

> 길이가 N이고 'A', 'B', 'C'로 이루어진 문자열 중 조건을 만족하는 문자열을 찾는 문제.
> `A가 a개, B가 b개, C가 c개일 때 K개의 쌍을 만드는 경우가 하나의 상태로, DFS + DP로 메모제이션하여 탐색`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
N,K = map(int,input().split())

answer = None
dp = set()

def dfs(string,a,b,c,k):

    global answer

    if answer is not None:
        return

    if (a,b,c,k) in dp:
        return 

    if k == K: # 한 문자열만 찾으면, 남은 문자열은 A로 채워서 출력
        answer = string + (N-(a+b+c))*'A'
        return
    
    if k > K or a+b+c >= N:
        return
    
    dfs(string+'A',a+1,b,c,k)
    dfs(string+'B',a,b+1,c,k+a)
    dfs(string+'C',a,b,c+1,k+a+b)
    dp.add((a,b,c,k))

dfs('',0,0,0,0)
print(answer if answer else -1)
```

[/tabs]

* SOLUTION 1
  * 전체 경우의 수: 3^30으로 경우의 수를 구하는 문제가 아니라, 조건을 만족하는 문자열 중 하나를 출력
  * 상태: A가 a개, B가 b개, C가 c개일 때 K개의 쌍을 만드는 경우가 하나의 상태
  * 메모제이션: 한 상태로 여러 번 도달하는 경우, 탐색이 여러 번 일어날 수 있으므로 메모제이션을 통해 시간초과 줄이기

## **코멘트**

* 리스트가 더 빠르긴 한데, 배열 사이즈 지정이 필요 없는 set으로 설정
* 조건을 만족하는 문자열의 개수가 아니라 조건을 만족하는 문자열 중 하나를 출력하는 문제라서, 가장 먼저 찾은 문자열에 A를 붙여서 출력한다.
