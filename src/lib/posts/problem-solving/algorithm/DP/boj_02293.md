# [백준 : 2293. 동전 1](https://www.acmicpc.net/problem/2293)

## **목표**

> N가지 종류의 동전으로 K원을 만드는 경우의 수를 구하는 문제.
> `unbounded knapsack으로 현재 선택한 동전으로 가방을 모두 채운 후, 다음 선택한 동전으로 가방을 모두 채우는 방식`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
import sys
sys.setrecursionlimit(10**6)

N,K = map(int,input().split())
arr = [int(input()) for _ in range(N)]

dp = [[-1]*(K+1) for _ in range(N)]

def dfs(idx,x):
    
    # 기저조건
    if not x:
        return 1
    
    # 마지막 동전 사용
    if idx >= N:
        return 0
    
    # 메모제이션
    if dp[idx][x] != -1:
        return dp[idx][x]

    # 재귀
    result = 0
    if x - arr[idx] >= 0:
        result += dfs(idx,x-arr[idx])
    result += dfs(idx+1,x)

    dp[idx][x] = result
    return result

print(dfs(0,K))
```

[/tabs]

[tabs: Solution 2]

```python
N,K = map(int,input().split())
arr = [int(input()) for _ in range(N)]

dp = [0]*(K+1)
dp[0] = 1

for a in arr:
    for i in range(a,K+1):
        dp[i] += dp[i-a]
print(dp[K])
```

[/tabs]

* SOLUTION 1
  * 탑다운 DP: 탑다운으로 풀이
  * 정렬 효과: arr를 정렬하는 방식이 시간이 더 적게 나옴. 첫 방문에서 큰 거부터 방문하면 메모제이션이 효과적으로 일어나지 않음
  * 작은 cost 동전부터 사용해야, DP 배열자체가 dense해짐
* SOLUTION 2
  * 바텀업 DP: 1차원 DP로 간단하게 구현

## **코멘트**

* 탑다운
* arr를 정렬하는 방식이 시간이 더 적게 나온다.
* 첫 방문에서 큰 거부터 방문하는 경우가 다수 생기게 되면, 메모제이션이 효과적으로 일어나지 않는다.
* 작은 cost 동전부터 사용해야, DP 배열자체가 dense해진다.
