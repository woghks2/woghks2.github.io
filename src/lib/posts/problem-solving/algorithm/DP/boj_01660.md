# [백준 : 1660. 캡틴 이다솜](https://www.acmicpc.net/problem/1660)

## **목표**

> N개의 블록을 사용하여 사면체를 만드는 최소 블록 단위 개수를 구하는 문제.
> `사면체 만드는데 필요한 블럭 단위를 미리 만들어놓고, i개를 사용해서 만들 때 블럭단위에 있는 t개 + dp[i-t]가 최소값인 경우 갱신`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
N = int(input())

dp = [1e9]*(N+1)

tetra = [(n*(n+1)*(n+2))//6 for n in range(1,121) if (n*(n+1)*(n+2))//6 <= N]

for t in tetra:
    dp[t] = 1

for i in range(2,N+1):
    for t in tetra:
        if i>t:
            dp[i] = min(dp[i],dp[i-t]+1)
        else:
            break

print(dp[N])
```

[/tabs]

* SOLUTION 1
  * 블록 단위: 사면체 만드는데 필요한 블럭 단위를 미리 만들어놓음
  * DP 전이: i개를 사용해서 만들 때, 블럭단위에 있는 t개 + dp[i-t]가 최소값인 경우 갱신

## **코멘트**

* python으로 잘 안돌아감
* O(100N)이라 안터질줄 알았는데 터져서 pypy로 풀이
