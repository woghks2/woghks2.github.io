# [백준 : 5557. 1학년](https://www.acmicpc.net/problem/5557)

## **목표**

> N개의 숫자 사이에 + 또는 -를 넣어 등식을 만드는 경우의 수를 구하는 문제.
> `DFS + DP로 배열을 탐색하면서 cumsum이 0미만, 20초과가 되는 경우에서 가지치기`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
N = int(input())
arr = list(map(int,input().split()))

dp = {}

def dfs(idx,cumsum):
    
    # 탈출조건
    if cumsum < 0 or cumsum > 20:
        return 0
    
    # 종료조건
    if idx == N-1:
        return 1 if cumsum == arr[-1] else 0
    
    # 메모제이션
    if (idx,cumsum) in dp:
        return dp[(idx,cumsum)]
    
    # 탐색
    dp[(idx,cumsum)] = dfs(idx+1,cumsum+arr[idx]) + \
                        dfs(idx+1,cumsum-arr[idx])
    return dp[(idx,cumsum)]

print(dfs(1,arr[0]))
```

[/tabs]

* SOLUTION 1
  * DFS + DP: 배열을 탐색하면서 cumsum이 0미만, 20초과가 되는 경우에서 가지치기를 해줌
  * 종료 조건: 마지막 인덱스에 도달하면 등식 성립 확인해서 맞으면 1, 아니면 0
  * 메모제이션: 이외의 경우에는 탐색 + 메모제이션
