# [백준 : 18244. 변형 계단 수](https://www.acmicpc.net/problem/18244)

## **목표**

> 인접한 자릿수 차이가 1이고, 연속으로 3번 이상 증가하거나 감소할 수 없는 변형 계단 수의 개수를 구하는 문제.
> `연속 1개/2개 증가/감소로 총 4개로 나누고, 초기 상태를 하나 추가해서 5개 상태로 나누어 DP 계산`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
N = int(input())
K = 10**9+7

# dp[상태][i번째 자리][숫자 j 선택]
dp = [[[0]*10 for _ in range(N)] for _ in range(5)]
dp[0][0] = [1]*10

for i in range(N-1):
    for j in range(10):
        for s in range(5): 
            
            if 1<=j<=9: # 1~9(j) 숫자는 0~8(j-1)에서 숫자가 들어온다
                if s == 1:
                    for ps in (0,3,4):
                        dp[1][i+1][j] += dp[ps][i][j-1]%K
                elif s == 2:
                    dp[2][i+1][j] += dp[1][i][j-1]%K
                    
            if 0<=j<=8: # 0~8(j) 숫자는 1~9(j+1)에서 숫자가 들어온다
                if s == 3:
                    for ps in (0,1,2):
                        dp[3][i+1][j] += dp[ps][i][j+1]%K
                elif s == 4:
                    dp[4][i+1][j] += dp[3][i][j+1]%K
                
print(sum(sum(dp[s][-1]) for s in range(5))%K)
```

* SOLUTION 1
  * 상태 구분: 초기 상태는 연속으로 몇 개 증가했는지 처리하기 애매하므로, 연속 1개/2개 증가/감소로 총 4개로 나누고, 초기 상태를 하나 추가해서 5개 상태로 나누기
  * DP 상태: 5개 상태마다 i번째 수에서 숫자 j를 골랐을 때 값을 저장

## **코멘트**

* 초기 상태는 연속으로 몇 개 증가했는지 처리하기 애매하다.
* 연속 1개/2개 증가/감소로 총 4개로 나누고, 초기 상태를 하나 추가해서 5개 상태로 나누기.
