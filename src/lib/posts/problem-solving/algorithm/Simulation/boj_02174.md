# [백준 : 2174. 로봇 시뮬레이션](https://www.acmicpc.net/problem/2174)

## **목표**

> 로봇들이 명령에 따라 이동할 때 벽이나 다른 로봇과 충돌하는지 확인하는 문제.
> `초기 방향 매칭 후 회전 방향 고려하기 (시계 방향으로 인덱스 매칭해서 풀기)`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
import sys
input = lambda : sys.stdin.readline().rstrip()

# 맵 사이즈
W,H = map(int,input().split())

# 로봇 수 / 명령 수
N,M = map(int,input().split())

# 방향 매칭
dire = {'E':0,'S':1,'W':2,'N':3}
step = {0:(1,0),1:(0,-1),2:(-1,0),3:(0,1)}

# 각 로봇 위치,방향
infos = [None]

# 맵 정보
maps = [[0]*(W+1) for _ in range(H+1)]

# 로봇 초기화
for number in range(N):
    x,y,d = input().split()
    x,y = int(x),int(y)
    maps[y][x] = number+1
    infos.append([x,y,dire[d]])

# 로봇 이동
error = False
for _ in range(M):
    number,cmd,t = input().split()
    number,t = int(number),int(t)
    if cmd == 'L':
        infos[number][2] = (infos[number][2]-t)%4
    elif cmd == 'R':
        infos[number][2] = (infos[number][2]+t)%4
    else:  # cmd == 'F'
        x,y,d = infos[number]
        dx,dy = step[d]
        
        # 모든 좌표에 대해서 충돌하지 않고, 맵 밖으로 나가지 않아야함
        for i in range(1,t+1):
            nx,ny = x+dx*i,y+dy*i
            if 0<nx<=W and 0<ny<=H:
                if maps[ny][nx]:
                    print(f'Robot {number} crashes into robot {maps[ny][nx]}')
                    error = True
                    break
            else:
                print(f'Robot {number} crashes into the wall')
                error = True
                break
        # for else로 에러가 없는 경우만 좌표 이동시키기
        else:
            maps[y][x] = 0
            maps[ny][nx] = number
            infos[number] = [nx,ny,d]  
            
    if error:
        break
    
if not error:
    print('OK')
```

* SOLUTION 1
  * 방향 매칭: 초기 방향 매칭
  * 회전 방향: 회전 방향 고려하기 (시계 방향으로 인덱스 매칭해서 풀기)
  * 충돌 검사: 모든 좌표에 대해서 충돌하지 않고, 맵 밖으로 나가지 않아야 함
