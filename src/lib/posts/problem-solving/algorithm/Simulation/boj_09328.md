# [백준 : 9328. 열쇠](https://www.acmicpc.net/problem/9328)

## **목표**

> 열쇠를 모아 문을 열고 문서를 얻는 최대 개수를 구하는 문제.
> `BFS를 돌리면서 열쇠를 먹은 경우, 현재 상태를 변화시킨 후 변화된 상태에서 BFS를 또 돌리고 반복. 열쇠를 먹고나서 BFS를 돌렸는데 변화가 없는 경우 탐색이 끝남`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
from collections import deque
import sys
input = lambda : sys.stdin.readline().rstrip()

shift = {chr(i+97):i for i in range(26)}
dire = [(1,0),(0,1),(-1,0),(0,-1)]

def bfs(state):

    q = deque(starts)
    for door,loc in doors:
        if state&(1<<shift[door.lower()]):
            q.append(loc)

    visit = [[False]*w for _ in range(h)]
    while q:
        x,y = q.popleft()
        for dx,dy in dire:
            nx,ny = x+dx,y+dy
            if 0<=nx<w and 0<=ny<h:
                na = arr[ny][nx]
                if na == '.' and not visit[ny][nx]:
                    q.append((nx,ny))
                    visit[ny][nx] = True
                elif na.islower() and not visit[ny][nx]:
                    state = state|(1<<shift[na])
                    q.append((nx,ny))
                    visit[ny][nx] = True
                elif na.isupper() and not visit[ny][nx] and state&(1<<shift[na.lower()]):
                    q.append((nx,ny))
                    visit[ny][nx] = True
                elif na == '$' and not visit[ny][nx]:
                    q.append((nx,ny))
                    visit[ny][nx] = True
                    answer.add((nx,ny))
    return state

for _ in range(int(input())):
    h,w = map(int,input().split())
    arr= [list(input()) for _ in range(h)]

    stt = 0
    s = input()
    if s != '0':
        for key in s:
            stt = stt|(1<<shift[key])

    starts,doors = [],[]
    answer = set()
    for i in range(h):
        for j in range(w):
            a = arr[i][j]
            if (i==0 or i==h-1) or (j==0 or j==w-1):
                if a == '.':
                    starts.append((j,i))
                elif a == '$':
                    starts.append((j,i))
                    answer.add((j,i))
                elif a.islower():
                    starts.append((j,i))
                    stt = stt|(1<<shift[a])
                elif a.isupper():
                    doors.append((a,(j,i)))
    while True:
        nstt = bfs(stt)
        if stt == nstt:
            break
        stt = nstt
    print(len(answer))
```

* SOLUTION 1
  * BFS + 시뮬레이션: BFS를 돌리면서 열쇠를 먹은 경우, 현재 상태를 변화시킴
  * 상태 변화: 변화된 상태에서 BFS를 또 돌리고 반복
  * 탐색 종료: 핵심은 열쇠를 먹고나서 BFS를 돌렸는데 변화가 없는 경우 탐색이 끝남
  * visit 배열: 한 stage마다 visit을 만들어서 BFS를 반복하는 식으로 구현
