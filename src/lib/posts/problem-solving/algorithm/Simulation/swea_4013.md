# [SWEA : 4013. 특이한 자석](https://swexpertacademy.com/main/code/problem/problemDetail.do?contestProbId=AWIeV9sKkcoDFAVH)

## **목표**

> 4개의 자석이 연결되어 있고, 하나를 회전시키면 인접한 자석도 회전하는 문제.
> `리스트 내부에 큐 넣어서 구현. 인접 톱니끼리는 반대의 회전방향을 가짐. BFS로 이웃 톱니를 회전시키기`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
from collections import deque

inside = lambda x : 0<=x<4

TC = int(input())

for tc in range(1,TC+1):
    K = int(input())

    arr = [deque(list(map(int,input().split()))) for _ in range(4)]    
    cmds = [tuple(map(int,input().split())) for _ in range(K)]

    for cmd in cmds:
        sx,val = cmd
        sx -= 1

        V = [0]*4
        V[sx] = val
        Q = deque([sx])
        while Q:
            x = Q.popleft()

            if inside(x-1) and not V[x-1]:
                if arr[x-1][2] != arr[x][6]:
                    V[x-1] = -V[x]
                    Q.append(x-1)
                
            if inside(x+1) and not V[x+1]:
                if arr[x][2] != arr[x+1][6]:
                    V[x+1] = -V[x]
                    Q.append(x+1)

        for idx,val in enumerate(V):
            arr[idx].rotate(val)

    answer = sum(arr[i][0]*(2**i) for i in range(4))
    print(f"#{tc} {answer}")
```

[/tabs]

* SOLUTION 1
  * deque 사용: 리스트 내부에 큐 넣어서 구현
  * 회전 방향: 인접 톱니끼리는 반대의 회전방향을 가짐
  * 방문 처리: 현재 톱니를 돌리고 옆 톱니를 돌리는 과정에서, 이전에 돌렸던 톱니를 다시 돌리지 않기 위해 방문처리
  * BFS: BFS로 이웃 톱니를 회전시키기

## **코멘트**

* 회전량이 많은 경우에는 모듈러 연산을 통해서 줄일 수 있다.
* 자바에서는 음수 모듈러가 안돼서 후보정을 해줘야한다.
