# [백준 : 2593. 탑](https://www.acmicpc.net/problem/2593)

## **목표**

> 각 탑에서 왼쪽으로 레이저를 발사했을 때, 레이저가 닿는 탑의 번호를 구하는 문제.
> `스택을 사용하여 이전에 쌓인 값들 중 자신보다 작은 값들을 제거하고, 남은 값 중 가장 가까운 값 선택`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
import sys
input = sys.stdin.readline

N = int(input())
arr = list(map(int, input().split()))

stack = []
answer = []
for idx,val in enumerate(arr,start=1):

    while stack and stack[-1][1] < val:
        stack.pop()
    
    answer.append(stack[-1][0] if stack else 0)
    stack.append((idx,val))

print(*answer)
```

[/tabs]

* SOLUTION 1
  * 스택: 스택 기본 문제로 이전에 쌓아놨던 값들 중 자신보다 작으면 자신의 다음 값들은 이전 스택들의 값을 탐색할 수 없음
  * 제거: 나보다 작은 값들을 스택에서 빼주기
  * 레이저: 스택이 비어있으면 레이저가 만나지 않으니 0을, 아닌 경우 해당 인덱스를 출력
