# [백준 : 11000. 강의실 배정](https://www.acmicpc.net/problem/11000)

## **목표**

> N개의 강의를 모두 배정하기 위해 필요한 최소 강의실 개수를 구하는 문제.
> `정렬 + 스위핑 또는 힙을 활용하여 강의실 개수 최소화`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
import sys
input = sys.stdin.readline

N = int(input())
arr = []
for _ in range(N):
    s,e = map(int,input().split())
    arr.append((s,1))
    arr.append((e,-1))
arr.sort()

answer,cur = 0,0
for _,new in arr:
    cur += new
    answer = max(answer,cur)
print(answer)
```

[/tabs]

[tabs: Solution 2]

```python
import heapq as hq
import sys
input = sys.stdin.readline

N = int(input())
arr = [tuple(map(int,input().split())) for _ in range(N)]
arr.sort()

answer = 0
heap = []
for s,e in arr:
    if heap and heap[0] <= s:
        hq.heappop(heap)
    hq.heappush(heap,e)
    answer = max(answer,len(heap))
print(answer)
```

[/tabs]

* SOLUTION 1
  * 스위핑: 시작 시간을 +1, 종료 시간을 -1로 표현하여 정렬 후 누적합으로 최대 동시 강의실 개수 계산
* SOLUTION 2
  * 힙: 강의실 예약 쿼리가 들어오면 사용 현황(우선순위 큐)를 확인하고 가장 먼저 끝나는 강의실 확인
  * 진입 시간 s보다 같거나 빨리 끝나면, 그 강의실을 이어받음 (앞 강의를 힙에서 빼고 현재 강의를 넣기)

## **코멘트**

* 스위핑이 더 편한느낌
* 힙으로 푸는 방식은, 강의실 예약 쿼리가 들어오면 사용현황(우선순위큐)를 확인하고 가장 먼저 끝나는 걸 확인하면 된다.
  * 내가 들어가는 진입시간 s보다 같거나 빨리 끝나면, 그 강의실을 이어받으면 된다 (앞 강의를 힙에서 빼고 현재 강의를 넣기).
