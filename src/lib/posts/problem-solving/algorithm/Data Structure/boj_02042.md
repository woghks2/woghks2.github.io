# [백준 : 2042. 구간 합 구하기](https://www.acmicpc.net/problem/2042)

## **목표**

> 배열의 구간 [b, c] 합을 구하고, 특정 인덱스의 값을 변경하는 문제.
> `펜윅 트리로 구간합을 효율적으로 구하기 (세그트리 기본 문제)`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
import sys
input = lambda : sys.stdin.readline().strip()

def update(x,diff):
    while x <= N:
        tree[x] += diff
        x += x&(-x)

def cumsum(x):
    result = 0
    while x:
        result += tree[x]
        x -= x &(-x)
    return result

N,M,K = map(int,input().split())
arr = [0] + [int(input()) for _ in range(N)]
tree = [0]*(N+1)

for i in range(1,N+1):
    update(i, arr[i])

for _ in range(M+K):
    a,b,c = map(int, input().split())
    if a==1:
        diff = c - arr[b]
        arr[b] = c
        update(b,diff)
    else:
        print(cumsum(c)-cumsum(b-1))
```

[/tabs]

* SOLUTION 1
  * 펜윅 트리: 구간합 구하는데는 펜윅트리가 더 빠르다고 해서 펜윅트리로 풀이
  * 세그트리 기본: 세그트리 기본 문제
  * 홀수/짝수: 홀수들은 자기 자신 정보만, 짝수들은 특정 구간합을 가지고 있음

## **코멘트**

* 짝수들은 특정 구간합을 가지고 있다.
