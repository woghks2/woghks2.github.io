# [백준 : 10775. 공항](https://www.acmicpc.net/problem/10775)

## **목표**

> 비행기가 도착할 때마다 주어진 게이트 범위 내에서 배정 가능한 게이트에 도킹하는 문제.
> `그리디 + 유니온파인드로 항상 선택 가능한 범위 중 가장 큰 쪽을 선택하여 다음 쿼리 시 더 많은 선택지 제공`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
import sys
input = sys.stdin.readline

N = int(input())
M = int(input())

P = [i for i in range(N+1)]

def find(x):
    if x != P[x]:
        P[x] = find(P[x])
    return P[x]

answer = 0
for _ in range(M):
    x = int(input())
    px = find(x)

    if px == 0:
        break

    npx = find(px-1)
    if px != npx:
        P[max(px,npx)] = min(px,npx)
    answer += 1

print(answer)
```

[/tabs]

* SOLUTION 1
  * 그리디: 항상 선택 가능한 범위 중 가장 큰 쪽을 선택해야 다음 쿼리에서 더 많은 선택지 제공
  * 유니온파인드: P 배열을 자기 자신으로 초기화하여 현재 위치에 쿼리가 들어올 때 다음 도킹 가능 위치 저장
  * 경로 압축: find 함수에서 경로 압축을 통해 시간 복잡도 최적화
