# [백준 : 7453. 합이 0인 네 정수](https://www.acmicpc.net/problem/7453)

## **목표**

> 네 개의 배열에서 각각 하나씩 선택하여 합이 0이 되는 경우의 수를 구하는 문제.
> `AB에서 N^2, CD에서 N^2의 모든 경우의 수를 만들고 해싱으로 매칭하여 계산`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
from collections import defaultdict as dd
import sys

input = lambda : sys.stdin.readline().rstrip()
N = int(input())

A,B,C,D = [],[],[],[]
for _ in range(N):
    a,b,c,d = map(int,input().split())
    A.append(a); B.append(b); C.append(c); D.append(d)


# AB에서 가능한 조합의 최댓값 M을 찾는다. 등장횟수는 table에 기록
M = -float('inf')
table = dd(int)
for a in A:
    for b in B:
        v = a+b
        table[v] += 1
        M = max(M,v)

# C,D 배열을 정렬한다. 탐색을 하면서 가능한 조합은 숫자가 점점 커진다.
# M보다 커지면 더 이상 c와 남은 D의 조합을 탐색할 필요가 없다.
answer = 0
C.sort(); D.sort()
for c in C:
    find = False
    for d in D:
        v = c+d
        if -v in table:
            answer += table[-v]
            find = True
            last_v = v
        if find and last_v>M:
            break
print(answer)
```

* SOLUTION 1
  * 해싱: 투포인터 태그가 있긴 하지만 해싱이 더 직관적인 풀이라고 생각
  * 조합 생성: AB에서 N^2, CD에서 N^2의 모든 경우의 수를 생성
  * 매칭: AB에 저장된 숫자로 CD에 매칭되는 숫자는 유일하니 이 경우를 카운팅

## **코멘트**

* 시간 줄이는 아이디어는 어렵지않다.
* 정렬 + 투포인터로 풀어도되는데, 같은 숫자가 여러 번 등장해서 신경 쓸 부분은 있었을듯
