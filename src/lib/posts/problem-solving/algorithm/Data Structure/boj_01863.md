# [백준 : 1863. 스카이라인 쉬운거](https://www.acmicpc.net/problem/1863)

## **목표**

> 스카이라인에서 건물의 개수를 세는 문제.
> `스택을 사용하여 낮은 높이가 들어오면 이전 건물을 제거하고, 높이가 높아지면 새 건물 추가`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
import sys
input = lambda : sys.stdin.readline().strip()
N = int(input())

answer = 0
stack = []
for _ in range(N):
    
    x,y = map(int,input().split())

    while stack and stack[-1] > y:
        stack.pop()
        
    if (stack and stack[-1] < y) or not stack:
        
        if y:
            stack.append(y)
            answer += 1

print(answer)
```

[/tabs]

* SOLUTION 1
  * 스택: 입력이 들어오면서 낮은 높이의 경우, 이전에 있었던 건물로 생각
  * 건물 추가: 스택이 비어있을 때 y>0인 건물이 들어오면 +1, 스택의 마지막보다 더 큰 건물이 들어오면 +1
  * 예외 처리: 건물 높이가 0이고 스택이 비어있는 경우에 +1 하는 예외가 발생해서 y가 양수인 경우에만 정답처리
