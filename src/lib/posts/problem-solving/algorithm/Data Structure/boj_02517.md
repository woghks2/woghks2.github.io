# [백준 : 2517. 달리기](https://www.acmicpc.net/problem/2517)

## **목표**

> 선수들의 실력을 순차적으로 입력받아, 각 선수마다 자기보다 빠른 선수가 몇 명인지 계산하는 문제.
> `좌표 압축 + 펜윅 트리로 값이 매우 크고 상대적인 대소 관계만 중요한 경우 처리`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
import sys
input = lambda : sys.stdin.readline().strip()
INF = float('inf')
N = int(input())

arr = [INF] + [int(input()) for _ in range(N)]
fenwick = [0]*(N+1)
table = {val:idx for idx,val in enumerate(sorted(arr,reverse=True))}

def update(x,diff):
    i = x
    while i<=N:
        fenwick[i] += diff
        i += i&(-i)

def query(x):
    result = 0
    i = x
    while i:
        result += fenwick[i]
        i -= i&(-i)
    return result

for val in arr[1:]:
    idx = table[val]
    print(query(idx)+1)
    update(idx,1)
```

[/tabs]

* SOLUTION 1
  * 좌표 압축: 값이 매우 크고 상대적인 대소 관계만 중요하므로, 좌표 압축 후 펜윅 트리 사용
  * MLE 방지: 10억에 가까운 값들을 트리에 모두 저장하면 MLE 발생하므로 좌표 압축 필요
  * 순차 처리: 입력이 순차적으로 들어오므로, 자기보다 빠른 선수가 몇 명인지 카운팅
