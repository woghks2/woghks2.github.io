# [백준 : 2696. 중앙값 구하기](https://www.acmicpc.net/problem/2696)

## **목표**

> 수를 순차적으로 입력받아 홀수 번째 입력마다 현재까지의 중앙값을 구하는 문제.
> `최대 힙과 최소 힙 두 개를 사용하여 힙에서 뽑으면 중앙값이 나오도록 조작`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
import sys
import heapq as hq

input = lambda : sys.stdin.readline().strip()

TC = int(input())
for tc in range(1,TC+1):
    
    N = int(input())
    low,high = [],[]
    
    answer = []
    arr = []
    p,q = divmod(N,10)
    for i in range(p+(q!=0)):
        arr.extend(list(map(int,input().split())))
    
    for idx,x in enumerate(arr,start=1):
        
        hq.heappush(low,-x)
        
        if high and -low[0] > high[0]:
            hq.heappush(high,-hq.heappop(low))

        if len(low) > len(high) + 1:
            hq.heappush(high, -hq.heappop(low))
            
        elif len(low) < len(high):
            hq.heappush(low, -hq.heappop(high))
    
        if idx%2:
            answer.append(-low[0])
    
    p,q = divmod(len(answer),10)
    print(len(answer))
    for i in range(p+(q!=0)):   
        print(*answer[10*i:10*i+10])
```

* SOLUTION 1
  * 힙: heap[0]에는 항상 루트노드가 위치한다는 사실을 활용
  * 최대 힙/최소 힙: 최대 힙과 최소 힙 두 개를 사용하여 힙에서 뽑으면 중앙값에 가까운 값이 나오도록 조작
  * 균형 유지: 최소힙이나 최대힙이나 기준 하나 정해놓고, 입력을 받았을 때 중앙값을 한 쪽에 몰아줘서 출력하게 만들어줌
