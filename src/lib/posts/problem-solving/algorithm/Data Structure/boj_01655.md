# [백준 : 1655. 가운데를 말해요](https://www.acmicpc.net/problem/1655)

## **목표**

> 수를 하나씩 추가할 때마다 현재까지 입력된 수 중 중앙값을 출력하는 문제.
> `최대 힙과 최소 힙 두 개를 사용하여 힙에서 뽑으면 중앙값이 나오도록 조작`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
import sys
import heapq as hq

input = lambda : sys.stdin.readline().strip()

N = int(input())
low = []  
high = [] 

for _ in range(N):
    x = int(input())

    hq.heappush(low,-x)

    if high and -low[0] > high[0]:
        hq.heappush(high,-hq.heappop(low))

    if len(low) > len(high) + 1:
        hq.heappush(high, -hq.heappop(low))
        
    elif len(low) < len(high):
        hq.heappush(low, -hq.heappop(high))

    print(-low[0])
```

[/tabs]

* SOLUTION 1
  * 힙: heap[0]에는 항상 루트노드가 위치한다는 사실을 활용
  * 최대 힙/최소 힙: 최대 힙과 최소 힙 두 개를 사용하여 힙에서 뽑으면 중앙값에 가까운 값이 나오도록 조작
  * 균형 유지: 최소힙이나 최대힙이나 기준 하나 정해놓고, 입력을 받았을 때 중앙값을 한 쪽에 몰아줘서 출력하게 만들어줌

## **코멘트**

* 최소힙이나 최대힙이나 기준 하나 정해놓고, 입력을 받았을 때 중앙값을 한 쪽에 몰아줘서 출력하게 만들어준다.
* pq 두개 쓰거나, q 여러개 쓰는 문제는 봤던거라 어렵지 않게 떠올릴 수 있었다.
