# [백준 : 2357. 최솟값과 최댓값](https://www.acmicpc.net/problem/2357)

## **목표**

> 배열의 구간 [a, b]에서 최솟값과 최댓값을 구하는 문제.
> `세그먼트 트리로 최솟값과 최댓값을 튜플로 저장하여 한 번에 처리`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
import sys
input = lambda : sys.stdin.readline().strip()

N,M = map(int,input().split())
arr = [int(input()) for _ in range(N)]
tree = [0]*(4*N)

def build(x,s,e):
    if s==e:
        tree[x] = (arr[s], arr[s])
        return tree[x]
    m = (s+e)//2
    left = build(2*x+1,s,m)
    right = build(2*x+2,m+1,e)
    tree[x] = (max(left[0],right[0]), min(left[1],right[1]))
    return tree[x]

def update(x,s,e,idx,val):
    if s==e:
        tree[x] = (val,val)
        return tree[x]
    m = (s+e)//2
    if idx<=m:
        left = update(2*x+1,s,m,idx,val)
        right = tree[2*x+2]
    else:
        left = tree[2*x+1]
        right = update(2*x+2,m+1,e,idx,val)
    
    tree[x] = (max(left[0],right[0]), min(left[1],right[1]))
    return tree[x]

def query(x,s,e,l,r):
    if l<=s and e<=r:
        return tree[x]
    if e<l or s>r:
        return (-float('inf'),float('inf'))
    
    m = (s+e)//2
    left = query(2*x+1,s,m,l,r)
    right = query(2*x+2,m+1,e,l,r)
    result = (max(left[0],right[0]), min(left[1],right[1]))
    return result

build(0,0,N-1)

for _ in range(M):
    a,b = map(int,input().split())
    answer = query(0,0,N-1,a-1,b-1)
    print(*answer[::-1])
```

* SOLUTION 1
  * 세그먼트 트리: 세그트리 2개 또는 한 번에 튜플로 받아서 처리
  * 튜플 저장: 최솟값과 최댓값을 튜플로 저장하여 한 번의 쿼리로 모두 구함
  * 효율성: 세그트리를 2개 만드는 것보다 튜플로 저장하는 것이 메모리 효율적
