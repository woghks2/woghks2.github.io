# [백준 : 11658. 구간 합 구하기 3](https://www.acmicpc.net/problem/11658)

## **목표**

> 2D 배열에서 구간 합을 구하고, 특정 위치의 값을 변경하는 문제.
> `2D 펜윅 트리로 구간 합을 효율적으로 구하기 (1-based 인덱싱)`

## **문제 풀이**

### **Python**

[tabs: Solution 1]

```python
import sys
input = sys.stdin.readline

N,M = map(int,input().split())
arr = [[0]*(N+1)] + [[0] + list(map(int,input().split())) for _ in range(N)]
tree = [[0]*(N+1) for _ in range(N+1)]

def update(x,y,diff):
    i = y
    while i<=N:
        j = x
        while j <= N:
            tree[i][j] += diff
            j += j & -j
        i += i & -i

def cumsum(x,y):
    result = 0
    i = y
    while i:
        j = x
        while j:
            result += tree[i][j]
            j -= j & -j
        i -= i & -i
    return result

def range_sum(x1,y1,x2,y2):
    return cumsum(x2,y2) - cumsum(x2,y1-1) - cumsum(x1-1,y2) + cumsum(x1-1,y1-1)

for y in range(1,N+1):
    for x in range(1,N+1):
        update(x,y,arr[y][x])

for _ in range(M):
    cmd,*info = list(map(int,input().split()))
    if not cmd:
        y,x,val = info
        diff = val - arr[y][x]
        arr[y][x] = val
        update(x,y,diff)
    else:
        y1,x1,y2,x2 = info
        print(range_sum(x1,y1,x2,y2))
```

* SOLUTION 1
  * 2D 펜윅 트리: 구간합 구하는데는 펜윅트리가 더 빠르다고 해서 펜윅트리로 풀이
  * 1-based 인덱싱: 둘 다 1-based로 맞춰주고 시작하기
  * 2D 구간 합: 4개의 누적합을 조합하여 구간 합 계산
